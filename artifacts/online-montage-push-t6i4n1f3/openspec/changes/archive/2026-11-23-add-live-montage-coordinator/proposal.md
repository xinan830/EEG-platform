# Proposal

## Why

实时导联目前只驱动波形投影，RBP、PSD、STFT 和实时地形图仍从采集流元数据自行选择通道，切换导联后可能出现波形与算法来源不一致。采集会话需要一个唯一、可校验的导联选择快照供实时消费者读取，同时保持原始记录和离线回溯链路独立。

## What Changes

- 在采集会话运行时增加唯一的实时导联协调状态及单调递增配置修订。
- 波形展示和实时算法配置从同一不可变快照解析有序通道；切换时在样本边界应用，并使旧算法窗口/迟到结果失效。
- 明确输入样本维持采集流顺序、行优先 `(samples, channels)`、单位 V 和硬件 sample counter 时间坐标；显示滤波与算法预处理仍独立。
- 保留当前仅预览状态可切换、录制入库快照不可变的规则；无效或算法不支持的映射明确报不可用，不回退到其他通道。
- 不更改离线回溯协调器、算法公式或原始写盘格式；仅在实时算法传输契约确实无法携带导联身份/修订时，才增加有版本字段的实时消息元数据。

## Capabilities

### New Capabilities

- 无。该工作扩展现有采集实时导联切换能力。

### Modified Capabilities

- `desktop/acquisition-preview-montage-switch`: 实时导联由仅影响波形的选择，扩展为波形与实时算法共享的版本化会话信号视图；原始流和录制快照继续保持不变。

## Impact

- 桌面端采集运行时、采集协调器、波形投影、实时分析 ViewModel/桥接输入及其测试。
- 后端算法公式与回溯执行器保持不变；如现有实时 API 输入契约不足以表达同一有序导联投影，实施中先验证并仅扩展实时传输字段，禁止在桌面端复制科学公式。
- 不新增依赖或持久化迁移。兼容性按导联快照的通道配置指纹与算法声明的输入通道类型校验；实现迁移仅影响运行中的实时会话。
- 失败时保留上一有效快照或将算法视图标记为不可用；不得把错误映射静默替换为 REF/原始通道。
