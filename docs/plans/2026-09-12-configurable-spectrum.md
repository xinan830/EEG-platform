# 可配置频谱分析实施计划

## 目标

冻结 `offline-spectral-v3` 的数学契约，在不改变预处理、Welch、频段与质量门结果的前提下，新增 `offline-spectral-v4-configurable` 安全配置层。

## 本轮范围

- 定义统一 `AnalysisConfig` 请求 Schema。
- 静态 PSD 支持自定义开始与结束时间，严格拒绝越界。
- 动态 PSD 支持 5/10/20/30 秒窗口和 1/2/5 秒刷新步长。
- 分析通道保持用户请求顺序。
- 时频图纳入同一配置 Schema，使用 4 秒窗/1 秒步进的固定数学契约。
- 响应同时返回请求区间、实际区间、warm-up 状态和实际执行配置。
- 生成稳定的 `analysis_config_hash`，用于结果追溯。
- 算法校验弹窗展示请求参数、实际执行参数、指纹及逐通道频段结果。
- 验证 v4 使用 v3 默认参数时，PSD、Band Power、RBP 与 v3 一致。

## 不在本轮开放

- 修改滤波器、Welch segment、overlap、窗函数和频段边界。
- 保存分析模板。
- 临床诊断结论。

这些参数在独立测试覆盖和配置迁移规则完成后再开放，避免破坏 v3 基准。

- [x] 冻结 v3 契约并新增 v4 配置 Schema。
- [x] 增加 configured spectrum API 和可追溯响应。

- [x] 同步算法校验弹窗。
- [x] 补 API、服务、前端和 v3-v4 等价测试。
- [x] 更新算法文档与变更记录。
