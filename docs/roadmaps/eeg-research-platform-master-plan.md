# 当前能力与后续方向

更新日期：2026-10-22。本页是能力地图，不是新的实施承诺或未完成任务清单。具体需求和验收条件由对应 OpenSpec change 管理。

## 当前实现

| 范围 | 当前能力 | 边界 |
| --- | --- | --- |
| 桌面 | WPF/.NET 10，设备设置、通道与导联、采集、记录和阅图 | 实机、驱动和硬件持续运行需独立验收 |
| 数据 | BDF/EDF 导入、WPF 原始记录注册及读取 | 原始文件不可变；缺样不补造 |
| 波形 | 显示滤波、导联投影、回放、游标和缓存 | 显示处理与科学分析分别声明 |
| 官方算法 | 九个独立算法包；共享 typed 输入/结果、运行调度和追溯 | 特殊公式、角色、预处理及质量门由算法拥有 |
| 动态策略 | 全量、按需、组合；声明式方向性复用 | 能力与工程验证逐路径登记，不能推断所有路径等价 |
| 结果 | Run、不可变 artifact、参数/身份/范围/质量和 provenance | 仅维护当前官方算法及结果格式，不转换旧结果 |
| 科研组织 | 本地 Project/Subject/Condition/Session、批量任务及导出 API | 不提供多租户身份/权限体系 |
| Definition/扩展 | 元数据、拓扑及 manifest 校验 | 无自定义图/公式执行器或第三方插件运行时 |

当前算法接入步骤、策略矩阵和实现路径分别见[作者指南](../algorithms/official-algorithm-development.md)、[管理基线](../algorithms/official-algorithm-management.md)、[执行清单](../algorithms/official-algorithm-execution-inventory.md)。

## 维护顺序

优先处理实际使用暴露的缺陷。先核对输入身份和范围，再定位科学实现或显示适配；修复时同步相关测试和当前说明。完成一个功能后核对 tasks、证据和提交范围，避免再做无问题驱动的大规模整理。

新增算法采用现有模块流程。只有新数据源、新结果类型或新的执行语义确有需要时，才扩展公共契约。

## 尚未承诺的方向

算法接入阅图工作区、更广的设备支持、更多算法、真实长记录性能改进，以及第三方执行能力，均需按具体需求单独评估。API 或数据模型已存在不代表相应 UI 已完成；自动化回归也不替代实机或人工验收。

本项目不因工程测试通过而具备临床有效性或医疗器械认证。验证范围见[证据索引](../validation/README.md)。
