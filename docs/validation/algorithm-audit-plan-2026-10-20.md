# 九个官方算法全面审计计划

日期：2026-10-20<br>
范围：后端官方算法的科学契约、实现、质量门、时间/单位、数值复现和可追溯性。桌面端结果链路只核验其是否忠实呈现后端结果，不在本计划中重构通用结果管线。<br>
当前基线：9 个可运行模块——PSD、STFT、Peak Frequency、IAPF、Band Ratio、Theta/Beta、RBP、FAA、离线 Brainbeat。离线 Brainbeat 与旧实时 BrainBeat 的有状态 IAPF/EMA 链路不是同一算法，审计和结论必须分开。

## 目标和结论边界

### 2026-10-20 执行状态补记

阶段 0–4 已完成；阶段 3 合成数值证据和阶段 4 动态/稳健性证据分别见：

- [官方算法独立数值参考验证](2026-10-20_official-algorithm-independent-reference.md)
- [官方算法动态与稳健性验证](2026-10-20_official-algorithm-robustness.md)

阶段 5 尚未达到授权真实记录门槛，数据登记与证据差距见 [真实记录验证状态](2026-10-20_official-algorithm-real-data-blocker.md)。历史真实记录报告仅作为既往工程证据，不自动等同于当前算法基线版本验证。九算法阶段性 B/C 评级及 backlog 见 [评级与问题清单](2026-10-20_official-algorithm-audit-rating-backlog.md)。最终自动化检查：全量 backend/tests 825 passed（含 5 条已登记退化数值 warning），WPF 测试 841 passed，OpenSpec strict validation 和 git diff --check 通过。第 6 章保持未完成，故 change 不归档。没有工程/数值或临床有效性的合并结论。

本计划要回答：每个算法的已声明定义是否落实在代码中；相同输入与固定版本能否复算；单位、通道、绝对时间、窗口、质量门和不可用状态是否正确传递；目前证据足以支持什么结论、还缺什么证据。

审计结论分为三类，禁止混用：

1. **工程正确性**：代码实现符合冻结契约，边界和失败语义有自动化测试。
2. **数据集上的数值复现**：独立实现读取同一原始样本，在锁定参数下与平台结果达到预先登记的容差。
3. **临床/诊断有效性**：需要预先设计的临床研究、标签、统计功效和伦理/数据治理；工程测试或数值复现不能推出这一结论。

“算法好/不好”不作为单一分数。每个算法分别给出工程实现、独立复算、边界覆盖、来源追溯四项状态（通过/有条件/未验证/失败），并附证据、版本和限制。发现不符合既有契约的行为才记为缺陷；契约本身有歧义时先记录为科学决策项，不擅自改公式。

## 执行原则

- 每次比较固定原始文件字节身份、记录身份、通道及顺序、参考方式、滤波顺序、采样率、绝对样本范围、窗口计划、科学版本、实现身份、配置摘要和运行环境。
- 独立参考实现直接读取原始样本，不以平台最终 PSD/频谱/指标作为输入；明确登记独立代码、库版本和 `rtol`/`atol`。
- 每个窗口验证实际起止样本（左闭右开）、窗口锚点、warm-up、质量状态、失败码和 `null`。不可用不能以零、上一窗口值或插值代替。
- 科学前端只核对并展示后端输出；不写第二份 EEG 公式来“验证”。
- 测试样本不提交真实 EEG 或身份信息。持久化验证结果时使用 ValidationRun/安全 artifact，报告只保留必要的脱敏标量、轴、哈希与错误摘要。
- 任何公式、滤波、质量门、通道角色或输出语义变更，先开 OpenSpec change、确定版本迁移语义，再实现；不得在审计过程中顺手改公式。

## 九算法专属核查重点

| 算法 | 必查科学与数据契约 | 必做独立/边界验证 |
|---|---|---|
| PSD | Welch 段长、Hann、重叠、去趋势、平均策略、V²/Hz、频率网格、滤波/陷波、坏段排除、带功率输出 | 独立 Welch 对照；整段与动态窗逐点 PSD；Nyquist 与频段裁剪边界；质量门和间隙不插补 |
| STFT | 4 秒窗、1 秒步长、窗中心时间轴、线性/对数功率单位、内部时间相对窗口还是文件绝对时间、坏帧处理 | 独立 FFT 对照每个矩阵元素；PSD/STFT 对齐窗的可解释比较；窄频段、短记录、动态矩阵维度 |
| Peak Frequency | 参数频段、包含边界、频率离散网格、并列峰策略、不插值、PSD 通道选择 | 已有 tie 测试扩展到边界 bin/空频段/频率不完整/多通道顺序；独立从原始 EEG 到峰值复算 |
| IAPF | 1/f 拟合范围与排除 Alpha 区间、拟合方法、Alpha 范围、峰值 prominence 门限、峰/重心选择和无结果语义 | 拟合点不足、非有限/非正输入、平坦谱、无 Alpha bin、低 prominence、边界 IAPF；独立拟合参考；确认生产输入约束是否充分 |
| Band Ratio | 分子/分母边界、重叠策略、边界线性插值梯形积分、V²功率、无量纲结果、分母门限 | 手算可解析谱与独立积分；零/非有限/负功率、相接/重叠/超出频率轴、边界精确落 bin |
| Theta/Beta | IAPF 依赖、个体化 Theta/Beta 边界公式、功率积分、分母语义、同通道来源、失败传播 | IAPF 靠近上下边界及导致空/负宽频段时的行为；独立端到端复算；错误码/质量状态一致性 |
| RBP | 1–4/4–8/8–13/13–30/30–50 Hz、同一 PSD、总和归一化、50 Hz 陷波对 Gamma 的影响、Nyquist 必须高于 50 Hz、旧四频段版本兼容 | 五频段中间功率和比例独立复算；比例和约为 1；Nyquist=50/低于 50、notch 开关/滤波边界、历史 v1/v2 分流 |
| FAA | 明确 F3/F4 原始来源、连续预处理次序、2 秒 Hann epoch、50% overlap、成对质量门、Alpha 积分和 `ln(P_F4)-ln(P_F3)` | 独立 paired-epoch FFT；左右输入互换符号关系；相同/缺失通道、少于最少干净 epoch、坏 epoch 配对和短范围 |
| Brainbeat（离线） | 显式且不同的 Fz/Pz 来源、每窗 IAPF、相对 Theta(Fz)/相对 Alpha(Pz)、分母和 epsilon、无跨窗 EMA | 独立端到端复算；不同执行顺序结果相同；单窗变化不影响邻窗；失败 null；与实时状态性 BrainBeat 明确区隔 |

## 优先级与停止条件

**P0（先做）**：完成阶段 0–1；核实 IAPF/Theta-Beta 频率边界风险、各模块真实 runnable 状态、时间/单位和质量门契约。P0 只确认问题，不改公式。<br>
**P1**：补阶段 2 的边界测试和阶段 3 合成信号独立复算，优先覆盖已有疑点和当前没有独立参考的模块。<br>
**P2**：选定并批准脱敏真实数据集，完成阶段 4–5 的端到端复核。没有合法、稳定的数据集时，不伪造“真实数据通过”；记录阻塞和所需的数据治理决策。<br>
**P3**：基于前述证据评级，分别决定工程修复、算法版本更新、性能优化或临床研究。

以下情况必须暂停该项算法的通过评级并升级审查：公式/频段定义来源不明；数据身份或参数无法固定；样本坐标与秒数不一致；错误结果被零值或旧值掩盖；独立参考复用生产输出；真实数据授权/脱敏不充分；数值差异通过放宽容差而非解释消除。

## 验收和最终报告格式

每个算法最终记录：ID 与版本；用途及不适用范围；输入通道/参考/滤波；绝对范围与样本范围；公式与输出单位；质量门及失败状态；自动化测试结果；独立参考方法与容差；合成/真实数据覆盖；误差统计；已知限制；评级和建议动作。总报告给出跨算法共性问题，但不得把不同科学定义强行归一为同一公式。

评级建议：

- **A：证据充分**——契约、边界、独立复算和目标数据集验证均通过；仅表示工程/数值证据充分，不表示临床有效。
- **B：工程可靠，外部证据有限**——实现和自动化验证扎实，但真实数据独立复算覆盖有限。
- **C：证据不足**——关键边界、独立参考或 provenance 缺失，暂不建议据此作强科学解释。
- **D：发现契约违例**——有可重复证据表明实现违反已批准的科学/数据契约；应停用受影响的解释或版本，修复后重验。

评级必须给每项证据链接和覆盖范围；未测项目标记“未验证”，不从平均分或其他算法结果推断。
