# 常见问题与排查

本文只给出安全、可逆的初步检查。涉及硬件红灯、采集卡死或数据异常时，先停止记录并保留日志，不要反复拔插或重复启动设备流。

| 现象 | 先检查 | 建议处理 |
|---|---|---|
| 导入记录没有出现在预期位置 | 从哪个项目详情发起导入、当前打开的项目 | 回到发起导入的项目详情，检查记录列表和导入完成提示 |
| 导入后看不到预期导联 | 原文件是否携带平台导联元数据/配套文件，侧车是否匹配 | 先查看原始通道视图及导入错误；不要用系统里的其他导联替代记录自身配置 |
| 导入提示映射索引重复或无效 | EDF/BDF 与侧车是否来自同一次导出 | 保持配套文件同源、同目录后重新导入；不要复制其他数据的侧车 |
| 记录的算法入口不可用 | 记录状态、采样率、所选通道/导联、当前时间窗 | 查看质量门和输入原因；改用符合要求的通道/窗口后重算 |
| 坏段在波形上有标记但似乎仍参与分析 | 当前策略是“标注”还是“拒收”，以及算法窗口是否与坏段重叠 | “标注”保留样本，只提供质量信息；选择“拒收”后也只有命中该坏段范围的对应窗口/通道受质量门控制。核对分析时间和通道，再查看算法质量状态 |
| 一个通道坏段影响了其他通道观感 | 是否查看的是通道级坏段/全通道汇总 | 在扫描结果中查看通道和时间范围；结合算法质量信息判断，不要只看整体色带 |
| ICA 审查结果要求重新确认 | 输入通道、预处理或坏段配置是否变化 | 按当前输入重新拟合和审查，再确认需要排除的成分 |
| 关闭阻抗后预览没有恢复或设备异常 | 实时采集状态、设备状态提示和日志 | 停止进一步切换阻抗/采集模式，保存日志和时间点，联系维护人员检查设备状态 |
| 采集期间阻抗按钮变灰 | 是否已开始记录 | 记录过程中按界面设计禁用阻抗检测；结束记录后再检测 |
| 编辑受试者/记录信息失败 | 当前项目、权限/服务连接和必填项提示 | 先确认记录归属项目与服务状态，再按错误提示重试 |

## 提交问题时记录

为便于复现，请提供：软件版本/提交号、操作路径、记录类型（不要上传未经授权的 EEG 文件）、时间窗口、所选通道/导联、预处理参数、算法名称、完整错误码和相关日志片段。先遮挡姓名、受试者编号、文件路径和设备序列号。

## 分场景排查步骤

### 导入文件后找不到记录

1. 返回发起导入时所在的项目详情页；导入记录归属这个项目。
2. 检查记录表的当前筛选和分页，确认没有停留在另一个项目。
3. 查导入完成/失败提示。失败时保留错误码和原始文件，不要先用另一份配套文件替换。
4. 如果提示成功但没有记录，记录发生时间、项目名称和文件摘要，请维护人员检查后端日志。

### 导入后通道/导联不对

1. 先从原始信号视图检查文件的通道标签和列数。
2. 确认 EDF/BDF 配套元数据是否与该文件同一次导出、同一目录保存。
3. 检查通道索引是否重复、越界或通道类型不匹配；错误侧车可能会被拒绝。
4. 看导联下拉框是否只包含该记录自身随附并校验通过的导联。普通 EDF/BDF 未必带有平台导联；不要用系统其他设备的导联代替。

### 算法按钮可用，但结果不可用/拒收

1. 记录当前算法窗口的起止时间以及所选通道/导联。
2. 打开质量状态/错误详情，判断是样本不足、采样率、缺通道还是坏段窗口拒收。
3. 检查所选时间和通道是否与报告中的坏段重叠；全局色带可能汇总多个通道，逐通道区间才决定目标输入是否受影响。
4. 在不改变原始记录的前提下，选择符合研究问题的时间窗或有效信号重新计算。

### 预览不动或阻抗检测异常

1. 如果仍在阻抗窗口中，使用“结束检测并预览”关闭阻抗模式。
2. 等待界面报告预览恢复，并观察设备状态和波形是否继续更新。
3. 如果波形没有恢复、设备报警或程序卡住，停止继续切换模式，记录时间、状态提示和日志。
4. 不要在故障时反复拔插放大器或重复启动采集流；交由熟悉该设备 SDK 的维护人员排查。

### 受试者编号/姓名没有显示

检查记录是否实际关联了受试者。仅填写文件元数据、修改记录名或打开项目并不会自动创建受试者关系；从记录行的“编辑记录信息”检查关联选择。修改受试者资料后，关联记录可能显示更新后的摘要。
