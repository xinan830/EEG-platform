# 截图目录

此目录用于存放本手册的界面截图。所有截图应由使用者在桌面客户端中真实截取，本轮只预留文件名和图注位置，不生成示意图或伪造界面。

## 放置规则

1. 按所属文档中的“截图待补”条目使用建议文件名。
2. 截图放在本目录，文件类型建议 PNG。
3. 截图前遮挡受试者编号、姓名、文件路径、设备序列号、真实 EEG 波形及其他不宜公开的信息。
4. 保持文字清晰，尽量只截取和操作步骤相关的界面。
5. 完成后，在对应 Markdown 文件中把“截图待补”提示替换为：

   `![简短说明](../screenshots/文件名.png)`

   `README.md` 位于 `user-guide/` 根目录，图片相对路径应使用 `screenshots/文件名.png`。

## 目录约定

截图文件直接放在本目录；如后续图片较多，再按功能拆成子目录，不提前建立空层级。
