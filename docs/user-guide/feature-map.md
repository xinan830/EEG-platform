# 系统功能地图

本页帮助使用者找到入口。具体点击步骤见各功能操作页。

| 功能区域 | 入口 | 主要用途 | 操作说明 |
|---|---|---|---|
| 总览 | 左侧“总览” | 查看设备与工作区概况 | [实时采集](features/acquisition.md) |
| 项目列表 | 左侧“项目列表” | 创建、选择和维护研究项目 | [项目、受试者与记录](features/projects-subjects-recordings.md) |
| 项目详情 | 项目列表中打开项目 | 导入 EDF/BDF、开始采集、浏览项目记录 | [导入导出](features/edf-bdf-import-export.md) |
| 采集准备 | 项目详情 →“开始采集” | 检查设备、通道/导联、采样率、量程和受试者信息 | [实时采集](features/acquisition.md) |
| 实时采集 | 采集准备 →“进入实时采集” | 预览波形、开始/暂停/完成记录、查看实时分析 | [实时采集](features/acquisition.md) |
| 数据回溯 | 项目详情中可回溯记录行的图标 | 播放记录、查看波形、事件、数据信息并运行当前记录分析 | [数据回溯](features/review-and-playback.md) |
| 算法工作区 | 左侧“算法列表” | 浏览算法目录并从独立工作区选择已完成记录 | [算法分析](features/algorithms-and-results.md) |
| 设置 | 左侧“设置” | 进入设备、通道、导联和其他配置页面 | [通道与导联](features/channels-and-montages.md) |

> 记录回溯以项目详情中可回溯的记录为入口。回溯页算法菜单中的算法以当前记录为上下文；左侧“算法列表”是另一个独立工作区。“报告”目前显示为入口但不可用，不要把它当作已开放的报告导出功能。

## 主要工作流

### 采集新数据

项目列表 → 选择或创建项目 → 项目详情 → 开始采集 → 采集准备 → 检查设备、通道/导联、采样率和量程 → 进入实时采集 → 检查预览波形 → 开始记录 → 可选暂停/恢复（暂停期间仍采集但该段不保存）→ 完成记录 → 返回项目详情核对记录状态。

### 导入已有数据

项目列表 → 打开目标项目 → 导入 EDF/BDF → 选择或新建受试者（可选）→ 开始导入 → 项目记录列表打开该数据 → 回溯和分析。

### 回溯并分析

项目记录 → 回溯 → 选择显示导联和视窗 → 可选配置科学预处理 → 在“算法”菜单运行分析 → 查看算法结果、质量状态和溯源信息。

## 页面之间的关系

### 项目列表与项目详情

项目列表负责选择、创建和维护研究项目。进入项目详情后才能看到该项目记录，并从当前项目发起导入或采集。导入文件或新采集记录都会归属发起操作的项目。

### 实时采集与数据回溯

实时采集连接设备并生成新记录；数据回溯读取已完成的记录。实时预览期间的波形和指标不能替代保存记录上的离线分析。若要复查已采集的数据，先完成记录，再从项目详情的记录表进入回溯。

### 算法列表与回溯页算法菜单

左侧“算法列表”进入独立算法工作区，适合浏览算法目录和设置已完成记录的运行。回溯页的“算法”菜单把当前已打开记录作为上下文，适合查看当前记录的分析面板。实时分析则位于采集工作区。这些入口各自有不同目标和时间范围，开始运行前确认当前页面和数据对象。

### 设置与单条记录

“设置”中维护设备通道、通道配置、导联配置、事件设置等可复用配置；采集准备时选择配置并形成新记录。导入 EDF/BDF 可能带有自己的通道映射和导联快照，回溯该文件时应以记录自身配置为准，不因全局设置变化而混用其他记录的导联。

## 常见入口误区

- 左侧有“报告导出”图标或回溯页有“报告”文字，不代表当前版本已开放可用报告流程。
- 项目列表中的算法入口和回溯页算法菜单不是同一个工作区。
- 采集预览不等于已保存记录；需要归档和后续回溯时要点击“开始记录”，结束时点击“完成记录”。
- 屏幕显示滤波不等于科学预处理；科学处理策略要从科学预处理入口确认。
- 项目详情里的记录名与受试者关联可编辑，但它们不会改变 EEG 样本或物理通道信号。

常见术语和数据单位见[数据与界面术语](getting-started/data-basics.md)。
