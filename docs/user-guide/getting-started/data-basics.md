# 数据与界面术语

本页解释在项目、记录、回溯和分析页面反复出现的名称。掌握这些概念后，可以分辨设备输入、屏幕波形和算法实际使用的信号。

## 项目、受试者和记录

- **项目**：组织一次研究工作的数据容器。采集或导入从项目详情发起，产生的记录归属该项目。
- **受试者**：项目中可选的参与者身份。将多条记录关联到同一受试者，便于项目内管理；不填写不会阻止导入或采集。
- **记录**：一次采集会话或一份导入文件在平台中的数据对象。记录名是可读标签；记录内容还包括时间、采样率、通道和来源等信息。
- **回溯**：打开已完成并可读取的记录，浏览历史波形、事件和分析输入。
- **Run/分析运行**：以指定算法、配置和输入数据执行的一次计算。运行结果不是原始记录，也不会通过改名改变源样本。

## 通道和导联

- **物理/原生通道**：设备放大器的一个硬件输入，或文件中的一个信号列。它有原始索引。
- **通道身份/映射**：把原生输入索引解释为 EEG、EOG、ECG 等类型以及电极名称的配置。
- **启用通道**：通道映射中允许作为有效 EEG 分析输入的通道。设备有物理输入不代表它必定启用或参与算法。
- **导联（montage）**：由输入通道按参考或公式组合出的分析/显示信号。例如 `F4-C4` 依赖 F4 与 C4 两个输入；缺少其中一个时，该输出就无法按原公式计算。
- **临时在线导联**：在实时采集/波形浏览中临时调整的一套显示配置。界面说明它仅用于普通波形，不参与算法；要做算法比较时应返回正式分析导联。

因此，记录表中的“信号通道数”、设备硬件输入数和导联输出数可能不同。排查差异时依次检查源文件/设备输入、通道映射和导联输出，不要只比较数字。

## 时间、采样率和窗口

- **采样率（Hz）**：设备每秒采集的样本数。采样率会影响可表示的频率范围，也会影响文件大小。
- **样本数**：信号中离散采样点的数量。数据时长由样本数和采样率共同决定。
- **文件时间/绝对秒数**：从整段记录起点计算的位置。回溯定位和算法窗口通常以这条时间轴为上下文；切换窗口时要核对目标仍在整段记录范围内。
- **显示时间基**：当前屏幕横轴显示多少秒。它只控制可视窗口，不改变数据时长或分析窗口。
- **算法窗口**：本次计算实际读取的起止片段。即使屏幕看得到更长波形，按需算法也可能只分析较短窗口。

浏览时把屏幕显示范围和算法计算范围分开确认。比较结果时要尽量使用同一记录时间段和同一算法窗口。

## 信号单位和绘图

EEG 电位常以微伏（µV）展示。科学计算链路内部使用伏特（V），两者相差 1,000,000 倍；前端/API 展示时可能转换为 µV。读取任何结果都应以图轴、字段名或结果面板明确标出的单位为准，不要仅凭数值大小推测单位。

滤波、参考、坏导插值和伪迹处理改变的是分析/显示所使用的信号版本，不等于覆盖源文件。导出整段原始信号时，导出内容仍是源信号；平台配套元数据用于恢复通道映射和导联信息。

## 常见状态词

| 状态词 | 用户可如何理解 |
|---|---|
| 预览 | 正在接收并显示设备波形，但还未开始正式保存记录 |
| 正在记录 | 正式记录会话已开始，采集样本写入记录 |
| 记录已暂停 | 记录保存暂停；设备预览可能继续，期间数据不应当作已保存样本 |
| 完成 | 记录会话已结束，可按记录状态查看或回溯 |
| 标注坏段 | 添加区间质量标记，原始样本仍保留；算法是否跳过取决于质量策略 |
| 拒收坏段 | 分析质量门根据区间和通道判定窗口不可用/屏蔽，不等于删除整段源文件 |
| 插值通道 | 波形由邻近电极空间估计，不是该电极直接测得的样本 |

## EDF/BDF 配套文件

EDF/BDF 是标准信号文件。平台导出时还可能生成同目录配套元数据文件，保存平台通道映射/导联信息。只传 EDF/BDF 仍可读取信号，但接收端不一定能恢复平台配置。配套文件必须与源信号成套保管，详见[EDF/BDF 导入与导出](../features/edf-bdf-import-export.md)。
