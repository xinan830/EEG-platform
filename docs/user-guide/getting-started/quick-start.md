# 快速上手

本页给出“导入已有记录”和“采集新记录”两条最短路径。两条路径最终都会在项目详情的数据记录表中形成记录，但来源不同：导入路径读取已有 EDF/BDF，采集路径从设备实时流创建新记录。

开始前确认后端服务可用，并知道本次数据应归属哪个研究项目。若只是熟悉界面，使用匿名测试文件或测试项目；不要把真实受试者信息放入公共截图或演示材料。

## 路径 A：导入 EDF/BDF

1. 在左侧打开“项目列表”，创建项目或选择已有项目。
2. 打开项目详情，点击“导入 EDF/BDF”。
3. 在文件选择窗口选取 EDF 或 BDF 文件。
4. 在导入对话框中可选择已有受试者，也可创建受试者；编号和姓名均为选填。
5. 点击“开始导入”，等待文件上传和校验完成。
6. 导入完成后，在该项目的数据记录表中确认记录名称、时长、采样率、通道数和受试者信息，再打开回溯页面。

导入完成后不要只看提示框。项目详情的记录表是确认归属位置的地方；如果记录没有出现，先检查是否仍在发起导入的项目中，以及导入提示是否明确成功。通道映射和导联随附规则见[导入与导出](../features/edf-bdf-import-export.md)。

导入的导联来源与文件携带的通道映射/导联信息有关。导入记录应在自己的记录上下文中回溯，不会因为当前系统另一个设备配置而自动获得一套无关导联。详见[导入与导出](../features/edf-bdf-import-export.md)。

## 路径 B：开始采集

1. 在“项目列表”中选择项目。
2. 点击“开始采集”，进入“采集准备”。
3. 检查设备连接状态，选择当前设备支持的通道配置、兼容导联和采样率。
4. 确认输入量程。若设备量程允许编辑，按硬件配置操作；不确定时不要随意更改。
5. 受试者编号和姓名可选填，也可选择已有受试者。
6. 点击“进入实时采集”后先观察预览波形，确认设备、通道和信号状态，再开始记录。
7. 记录完成后返回项目详情，确认新记录已出现。

正式开始记录前，先在预览状态检查信号是否存在、通道标签是否符合接线、波形是否有明显断线或异常饱和。开始记录后再观察记录状态和时长；“暂停记录”会在保存的数据中形成缺口，不适合用来暂停受试者实验而仍期待时间连续。完整采集操作见[实时采集](../features/acquisition.md)。

## 第一次使用建议检查清单

- 项目名称正确，知道文件和新记录会保存到哪个项目。
- 设备厂商提供的 SDK/驱动已按部署要求配置，采集准备页显示设备连接状态。
- 通道配置与真实插线一致，只启用实际使用的 EEG 输入；电极标签映射无误。
- 导联配置依赖的输入通道已启用，输出名称和参考关系符合实验方案。
- 采样率和输入量程符合设备能力及实验方案。
- 受试者信息是选填项；如填写，确认当前项目和受试者身份无误。
- 测试导入时保留 EDF/BDF 及其配套元数据文件；需要闭环恢复导联时，两者应成套保存。

## 两种路径的差别

| 项目 | 导入 EDF/BDF | 实时采集 |
|---|---|---|
| 数据来源 | 已有文件 | 连接中的 EEG 设备 |
| 项目归属 | 从项目详情发起导入 | 从项目详情进入采集准备 |
| 受试者 | 可选关联已有/新受试者 | 可选关联已有/新受试者 |
| 通道与导联 | 由文件通道和随附映射/导联决定；没有侧车时不保证有平台导联 | 由采集准备选择的设备通道配置和兼容导联决定 |
| 首次确认 | 核对导入记录摘要与导联目录 | 先预览信号，再开始正式记录 |

详细步骤见[实时采集](../features/acquisition.md)与[通道与导联](../features/channels-and-montages.md)。
