# 科学预处理与 ICA 审查

## 入口与作用范围

打开一条可回溯记录，在页面顶部点击“科学预处理”，或从“算法”菜单选择“科学预处理（坏导/坏段/ICA）”。工作区包含处理流程摘要以及坏导、坏段、眼电/心电去伪迹等步骤。先选定通道/导联和拟分析的片段，再检查处理输入。科学处理用于后续分析和科学预览，不覆盖原始记录；普通彩色波形、显示滤波和科学处理结果是不同视图。

完成步骤配置后关闭向导返回回溯页，再运行目标算法。修改通道身份、坏段策略或 ICA 输入后，相关扫描/审查状态可能失效，需要重新扫描或确认；以页面的状态提示为准。保存原始记录与保存科学处理结果是两件事，处理参数和证据由分析请求/结果关联。

## 推荐操作顺序

### 1. 检查科学滤波

在流程摘要中检查科学滤波设置和采样率是否符合实验方案。不要用回溯页顶部普通阅图滤波值代替科学滤波配置；算法实际使用情况以结果溯源字段/处理状态为准。低采样率下不满足频带条件的设置可能不可用，应使用界面允许的参数并查看提示。

每次分析前记录滤波、陷波和参考设置。零相位离线滤波是分析信号处理的一部分，不能和实时/浏览波形的显示滤波混为一谈；科学预处理预览的基线说明会显示当前科学滤波条件。

### 2. 坏导体检与处理

1. 打开“重参考前坏导检测与修复”。
2. 执行“一键坏导体检”，阅读每路通道的理由和量化指标。
3. 阅读每路通道的异常原因和指标，结合原始波形与接触记录判断，不要仅凭自动推荐处理。
4. 点击“仅选疑似坏导”作为候选起点，然后逐一取消误报、补选人工确认的异常通道；“清空勾选”可清掉当前选择。只有勾选的通道会进入坏导处理策略。
5. 选择“不处理”“重参考前安全排除”或“3D 球面样条插值”。排除会使选中通道不进入后续有效信号/参考计算；插值会用邻近好导估计波形，不是实测值。
6. 此步骤在重参考前执行。插值要求电极名称有可用 3D 坐标，并且存在足够的可用好导；不满足时查看不可用原因，不要把该通道当成已插值。

### 3. 坏段质控

1. 打开“坏段质控（爆幅 / EMG 肌电）”。
2. 设置或确认爆幅、肌电阈值，点击“一键扫描坏段”。
3. 检查检测区间、异常类别、通道范围和起止时间；点击列表条目可定位主波形。
4. 在“不处理”“仅标注区间”“掩膜为 NaN 剔除”中选择策略。“仅标注区间”保留样本并记录质量区间；“掩膜为 NaN 剔除”会按通道屏蔽命中区间，使与坏段冲突的后续分析窗口/样本不可用，具体范围以质量报告为准。策略不会从原始文件物理删除样本。

### 4. 眼电/心电去伪迹与 ICA

在“眼电/心电去伪迹”步骤选择“不处理”“可审查 Infomax ICA”“MNE SSP 眼电投影”或“EOG 线性回归”等当前界面提供的方法。先检查并保存记录中的通道身份/用途：专用 EOG 通道可作为眼电参考，ECG 通道可用于 ICA；用途设置不会把通道身份改成另一种物理通道。可选择多个 EOG 参考通道，具体组合受界面互斥和算法输入规则限制。

如使用 EEG 前额代理通道，只有在记录没有专用 EOG 且实验方案允许时才勾选相应选项。代理可能含真实脑电，不应默认当成专用眼电。

使用可审查 ICA 时：

1. 设置成分数和参考通道选项。
2. 点击“拟合 ICA 并打开审查”。
3. 逐个查看成分头皮图、波形和参考相关性信息。
4. 只有证据支持时才选择需要排除的成分，然后确认审查结果。
5. 如果改变了 ICA 输入（例如通道、预处理参数或坏段策略），重新审查确认，不要直接沿用旧成分编号。

ICA 结果是需要研究者审查的信号处理结果，不是自动医学诊断。保留处理参数和审查依据。

## 结果如何理解

- **标注**：把问题区间作为质量信息展示，是否参与特定计算取决于算法质量策略。
- **拒收/屏蔽**：对应分析窗口或受影响通道不参与该次科学计算；原始记录仍保留。
- **插值**：根据邻近电极估计坏导波形。插值是重建值，不能当作原始实测信号。
- **ICA/SSP/EOG 回归**：调整分析输入信号以抑制可解释的伪迹成分，必须保留方法、参考和排除信息。

完成设置后回到回溯页，开启科学预处理对比查看基线和处理结果，并检查坏段色带、输出通道、质量状态和参数溯源。科学预览用于观察处理前后波形；算法运行结果需在对应算法面板另行查看。如果通道被排除、窗口被拒收或预览不可用，先查看质量原因，再决定是否调整策略。

## 从扫描到分析的完整核对清单

| 阶段 | 要做什么 | 完成标志 |
|---|---|---|
| 输入确认 | 检查记录、通道顺序、导联、时间范围和采样率 | 页面显示的对象与实验记录一致 |
| 坏导 | 运行检测、人工复核候选、选择不处理/排除/插值 | 状态文字反映已选策略；插值通道有位置和支持导联 |
| 坏段 | 运行爆幅/EMG扫描、核对通道和区间 | 区间可在波形中定位，策略明确为不处理/标注/拒收 |
| 伪迹分离 | 配置 EOG/ECG 身份与用途，拟合并审查（如启用） | 选定的 ICA/SSP/回归配置已确认，未确认时不视为已应用 |
| 预览 | 查看科学基线、处理后波形和坏段色带 | 叠图状态为可用且图例含义明确 |
| 算法 | 在算法面板选择目标指标并运行 | 有新的结果状态/质量信息和输入证据 |

若输入改变后界面提示重新扫描或审查，应从受影响步骤开始重新执行。不要只修改流程配置后继续把之前的坏导报告或 ICA 成分列表当作当前输入结果。

## 阈值与研究记录

阈值会影响哪些时间段被报告为坏段；不同设备、受试者状态、采样率和实验任务下不一定适合使用同一组阈值。先按实验方案或项目预先规定的规则选择阈值，在记录中保留阈值、扫描区间和手工确认依据。不要为了让某张图看起来更平滑而反复调阈值，也不要把自动标记直接解释为生理异常。

## 处理策略的含义

- **不处理**：扫描结果可供查看，但不据此改变后续信号或质量门。
- **标注**：保留信号值并附加坏段区间信息；后续算法是否拒绝相关窗口取决于算法质量门。
- **拒收**：把坏段质量纳入后续分析判定。若当前计算窗口与某个通道坏段重叠，可能拒绝该通道窗口；它不是把整份记录或所有通道一概删除。
- **坏导排除**：不使用坏导进入后续处理/参考池。该通道不再是正常可分析输入。
- **坏导插值**：用空间邻近信息重建坏导；这是估计值，应在解读和报告中保留其插值状态。

以上策略均不删除 EDF/BDF 或采集的原始源记录。要验证“剔除是否生效”，同时查看策略、坏段通道、时间范围、算法窗口和质量状态，而不要仅看波形是否仍画出曲线。
