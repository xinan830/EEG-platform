# 算法分析与结果

## 算法入口

在已完成记录的回溯页面打开顶部“算法”菜单，选择与研究问题对应的入口。当前菜单包含科学预处理、RBP 相对频段功率、PSD 功率谱密度、频段数值核查、自定义频段、STFT 时频分析、额叶 Alpha 不对称性、个体 Alpha 峰频率、Theta/Beta 比值、脑节律指标、个体化 BrainBeat 和 TNK 脑指标组。顶部工具栏也有部分常用分析按钮。菜单名称是入口，不表示每个算法对每条记录都可用。

左侧“算法列表”是独立的算法工作区，可针对已完成记录查看算法目录并进入算法详情；回溯页菜单则以当前打开记录和波形时间位置为上下文。实时分析在采集页面运行。这三种入口的目标记录、时间窗口和结果呈现方式不同，执行前先确认当前页面、记录名称、分析范围、通道/导联及参数。

## 通用分析流程

1. 从项目详情打开目标记录的回溯，检查记录名称、状态、采样率和通道数。
2. 选择要分析的导联或原始信号视图，确认当前时间游标和分析窗口落在目标片段。
3. 如需应用科学预处理，先打开“科学预处理”核对参数和策略，再返回算法入口。仅扫描/查看报告不等于已经选择了处理策略。
4. 选择目标算法，确认通道/导联、窗口长度、频段或其他可编辑参数；如果有质量提示，先按提示检查输入。
5. 启动分析，等待界面显示完成或明确的失败/不可用原因。不要在等待时把旧结果误认作本次结果。
6. 查看图表坐标、单位、时间范围、通道、质量状态和溯源信息。无结果、拒收或不可用不等于数值为零。

## 结果阅读

- **RBP**：相对频段功率。先确认频段定义、分析通道/导联和时间窗口，再比较各频段数值。
- **PSD**：功率谱密度。读取频率轴和面板显示的功率单位；比较结果时保持通道、时间窗口和参数一致。
- **STFT**：展示信号随时间和频率变化的时频结果。结合色标、时间轴和频率轴读取，颜色不是绝对电压。
- **FAA、IAPF、Theta/Beta、脑节律、BrainBeat、TNK**：按结果面板给出的定义、单位、窗口和质量状态解释，不要仅凭算法简称推断结论。

算法结果是科研分析输出，不应单独当作临床诊断结论。导出或分享结果前确认输入记录、参数、预处理证据和质量状态。

### 结果核对清单

查看每个结果时依次确认：

1. **对象**：结果对应的 recording/项目、记录名称和所选受试者是否正确。
2. **信号**：使用的是原始通道还是某个导联输出；通道顺序和标签符合预期吗？
3. **时间**：显示的是整段结果还是当前位置附近的按需窗口？时间单位和区间是否正确？
4. **参数**：频段、窗口长度、参考和预处理参数是否符合本次分析方案？
5. **质量**：运行状态是成功、部分可用、拒收还是失败？是否有坏段、缺失值或输入通道不足的说明？
6. **溯源**：算法版本、输入来源、科学预处理指纹/证据是否随结果显示？

比较两次结果时，应尽量保持同一记录、同一时间范围、同一信号视图和同一组参数，只改变一个因素。否则差异可能来自输入而非算法本身。

## 全量、按需和实时分析的区别

| 运行方式 | 常见入口 | 适合的问题 | 操作前确认 |
|---|---|---|---|
| 按需窗口 | 回溯页算法面板 | 查看当前时间附近的一段分析 | 波形游标、窗口长度、所选导联 |
| 完整记录/项目 Run | 左侧算法列表的算法详情/执行区 | 对已完成记录执行较长范围的分析并保留运行结果 | 目标记录、分析范围、算法参数和运行目标 |
| 实时分析 | 实时采集页 RBP/PSD/STFT 等面板 | 观察当前设备流上的滚动指标 | 正在预览/采集、当前可用通道和实时数据状态 |

不同入口的结果不能只按算法名称直接比较。时间窗口、科学预处理配置和数据完整性可能不同；查看结果证据确认输入一致后再比较。

## 常见不可用原因

- 所选通道或导联不满足算法输入要求。
- 当前窗口样本不足或与坏段质量门冲突。
- 记录采样率不满足某处理步骤的频率要求。
- 数据尚未完成导入/采集，或记录状态不可回溯。
- ICA/去伪迹审查尚未确认，或确认后输入发生变化。

请优先查看界面给出的具体质量原因，再调整输入和参数。

## 按算法类型查看

### 频谱类：RBP、PSD 和 STFT

- 先核对采样率、时间窗、通道和滤波频带；这些参数决定频谱结果能覆盖的频率范围。
- PSD 输出功率谱密度；RBP 输出所选频段的相对功率。它们的值和单位不同，不能把两个面板的数字直接比较。
- STFT 同时展示时间与频率变化。先读取坐标和色标范围，再定位瞬态变化；色块颜色表示图例定义的强度，不是电压值。
- 改变分析窗口或频段后，重新运行并确认结果状态刷新。

### 标量/指标类：FAA、IAPF、Theta/Beta、脑节律和 TNK

- 确认算法需要的导联/脑区输入；某些指标只使用指定通道或通道对。
- 查看当前结果解释和单位，不要将单个标量脱离实验条件当成诊断阈值。
- 如结果显示不适用/输入不足，检查缺少的脑区或信号类型；不要为了让数字出现而随意映射其他输入。

### 自定义频段和数值核查

自定义频段和频段数值核查适合检查已有 PSD/RBP 或特定频率范围的结果。提交前确认频段上下限合法、目标导联与现有结果一致、时间窗口相同。若核查视图提示缺少已有结果，先运行对应的 PSD/RBP 分析，不要把空白结果当成频率功率为零。

## 结果异常时怎么排查

1. 先确认页面上显示的是本次运行结果，而不是前一次运行留下的结果卡片。
2. 检查目标记录和导联；如刚切换记录、通道身份或参考配置，关闭并重新打开分析面板以建立当前上下文。
3. 查看时间窗口是否越界、太短，或与坏段拒收区间重叠。
4. 检查所需输入通道是否真实存在、启用且名称映射正确。EOG/ECG 参考要确认是实际生理参考通道，而不是仅凭标签猜测。
5. 查看采样率对频带/时频参数的限制，并按错误码或质量原因处理。
6. 如果问题仍存在，记录 recording_id（若界面/日志可见）、分析入口、时间范围、通道/导联、参数、错误码和软件版本；遮挡身份信息后提交给维护人员。
