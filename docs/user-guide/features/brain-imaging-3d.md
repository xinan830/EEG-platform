# 3D 脑影像与空间可视化

“脑影像视图中心”把脑电空间分布、脑区图谱、功能连接、源定位以及 MRI/DTI 结构影像放在同一个工作区中。它是平台展示空间信息的主要入口；不同视图回答的问题不同，不能把渲染效果本身当作算法结论。

## 打开视图中心

1. 从主界面进入“设置”。
2. 打开“脑影像视图中心”。
3. 从左侧导航选择要查看的视图；顶部会显示当前类别和简要说明。
4. 若页面使用当前 EEG 通道位置，先检查通道配置中的电极名称和位置是否正确。错误或缺失的电极位置会影响空间分布的解释。

## 视图用途

| 分类 | 视图 | 适合查看 | 使用时留意 |
|---|---|---|---|
| 地形图与皮层图谱 | 皮层电位 | 连续电位在标准皮层表面的空间分布 | 这是空间插值后的表面显示；它不增加传感器实测信息。 |
| 地形图与皮层图谱 | 脑区图谱 | 脑叶、Desikan–Killiany 区域及 Yeo-7 网络分区 | 图谱用于空间定位和浏览，需结合数据来源及分析结果解释。 |
| 地形图与皮层图谱 | 头皮地形图 | 电极周围头皮表面的电位分布 | 电极映射及电极位置会影响插值结果。 |
| 脑网络与溯源分析 | 功能连接 | 通道/脑区间连接关系及枢纽分布 | 连接线取决于分析结果和显示阈值，不表示结构神经纤维。 |
| 脑网络与溯源分析 | 源定位（sLORETA） | 皮层候选激活区域与等效电流偶极子 | 源定位是模型估计，需结合头模型、导联和分析参数解读。 |
| 多模态结构影像 | 白质纤维（DTI） | 白质纤维走向和束形 | 支持查看 `.tck` / `.trk` 文件；方向着色通常为红色左右、绿色前后、蓝色上下。 |
| 多模态结构影像 | MRI 切片与剖面 | MRI 三切面及 3D 剖面，可查看结构影像 | 支持 `.nii.gz` 影像；若叠加分割或核团结果，应确认其与影像空间匹配。 |

## 怎样读空间视图

- **先看数据来源**：确认当前视图展示的是 EEG 电位、连接/源定位分析结果，还是导入的结构影像/纤维束。
- **再看空间映射**：EEG 空间视图依赖电极坐标与通道映射。若电极名称不能对应位置，空间图可能缺点或无法正确定位。
- **最后看颜色和连线含义**：颜色表示当前视图选择的数值场或方向编码；连接弧线表示连接分析结果。查看图例、阈值与单位后再解释。
- **把估计与测量区分开**：表面插值、源定位和连接分析都是基于数据与模型的派生结果，不等同于 MRI 直接成像或电极直接测得的皮层信号。

## 数据与解释边界

三维渲染用于帮助观察空间关系，不会自动修复通道映射、导联、头模型或影像配准错误。头皮/皮层电位显示需要可用的 EEG 电极位置；功能连接和 sLORETA 需要相应分析结果；DTI 与 MRI 视图需要兼容的输入文件。遇到空白、定位异常或模式不可用时，先检查数据是否已加载、输入文件类型、通道电极映射及对应分析状态，不要仅凭画面外观下科学结论。
