# 项目、受试者与记录

## 项目是什么

项目是采集记录和导入记录的组织容器。项目详情页汇总项目元信息与所属数据记录。新建、编辑或选择项目后，可继续采集或导入数据。

## 创建和选择项目

1. 打开左侧“项目列表”。
2. 点击“新建项目”，填写项目名称。项目编辑窗口还可以填写项目目录、说明、研究目的、项目标签、创建者、项目状态和备注；除界面标星字段外，其他信息按研究管理需要填写。
3. 项目目录默认由项目名称生成；如果需要指定位置，使用“选择自定义项目目录”。保存前确认目录，避免把数据放到非预期磁盘位置。
4. 在项目列表选中项目进入详情。项目列表也提供编辑和删除/移除项目等管理操作，操作前核对项目名称。
5. 项目详情会显示项目基本信息和记录表，并提供“导入 EDF/BDF”和“开始采集”入口。

采集过程中不能随意切换项目；先结束当前采集会话，再进行项目切换。

### 项目信息如何填写

- **项目名称**：用于项目列表和项目详情识别项目。
- **项目目录**：记录数据关联的目录位置；保存前确认可写、空间足够且符合本地数据管理规范。
- **说明/研究目的**：建议填写简短、可辨认的研究内容或问题，方便团队区分项目。
- **项目标签**：可用来归类项目；按界面提示输入并确认添加。
- **创建者、状态和备注**：用于管理记录，填写前遵守团队约定。

不要把受试者姓名、病历号或其他敏感身份信息写进公开可见的项目名称或标签，除非本地数据治理政策明确允许。

## 受试者信息

受试者用于把同一研究参与者的多条记录关联起来，便于在项目内识别这些记录属于同一参与者。它不是记录本身的名称，也不是必须的实验条件。编号和姓名都是可选信息：无需受试者关联时可以留空；需要追踪时，在采集准备或导入时选择已有受试者，或新建受试者并填写信息。

受试者可通过“编辑受试者”维护信息，也可在记录行的“编辑记录信息”中更新该记录关联的受试者。编辑受试者资料会同步影响关联记录的受试者显示；记录行显示的是名称/编号摘要，未关联时显示未设置或留空。

### 选择、新建和修改受试者

1. 在采集准备或 EDF/BDF 导入界面找到“受试者（选填）”区域。
2. 如果参与者已在当前项目中登记，从下拉列表选择对应受试者。
3. 如果列表中没有，使用新建/编辑区域填写编号或姓名；两者都可以留空，但若填写性别，界面要求同时提供编号或姓名。
4. 保存后确认下拉框当前选中的是预期对象，再继续采集或导入。
5. 要更正既有受试者资料时，打开“编辑受试者”，保存后检查关联记录显示是否更新。

如要删除受试者，系统会解除记录与该受试者的关联，但不会删除脑电数据。删除前确认这正是需要的行为；如只是要更名，使用编辑功能。

请遵守本地研究伦理和数据管理要求。姓名、编号等属于身份信息，截图和分享材料前应遮挡。

## 项目记录列表

项目详情的记录表会展示记录名称、采集时间、时长、采样率、信号通道数、状态、受试者和操作入口。通过列标题核对记录身份：同一项目记录较多时，建议结合记录名称、时间和时长三项确认，不要只依赖默认排序。根据记录状态，回溯入口可能不可用；未完成记录不能按普通已完成数据回溯。

每条记录右侧提供回溯图标和“更多选项”。“编辑记录信息”可修改记录名称及其受试者关联；“删除数据记录”会删除记录数据，不是仅从当前列表隐藏。删除前确认记录和项目无误，并按研究数据管理要求留存备份。

### 记录表字段

- **记录名称**：项目内识别记录的名称，可在编辑信息窗口修改。
- **采集时间**：记录开始时间，用于区分同名或重复采集的记录。
- **时长**：以保存记录的实际样本时长为准；暂停或中断时，不应假定时长内每个时刻都有样本。
- **采样率**：记录采样率，供读取波形和分析输入校验。
- **信号通道数**：当前记录有效信号的通道数；它不一定等于设备物理输入数量或文件头所有通道总数。
- **记录状态**：状态决定此条记录是否可以回溯。出现“已中止”等状态时，先查看完整性，不要直接作为完整试次分析。
- **受试者**：该记录的受试者关联摘要，未关联时为空/未设置。

### 编辑记录信息

1. 在项目详情找到目标记录行，先核对记录名称、采集时间和受试者。
2. 点击该行“更多选项” →“编辑记录信息”。
3. 修改记录名称；按需从受试者选择区域选择、创建或取消关联受试者。
4. 点击“保存”，然后回到记录表检查名称和受试者列已更新。

此操作维护的是记录显示名称和受试者关联，不会重命名或重写原始 EEG 样本本身。

## 项目列表的搜索和管理

项目较多时使用项目列表中的搜索/筛选定位目标项目。打开前核对项目名称和状态，避免在相似名称的项目中导入或开始采集。项目行的编辑操作用于维护项目资料；删除/移除项目与删除单条数据记录是不同操作，执行前仔细阅读确认提示，确认页面说明的数据目录影响范围。

如果项目详情显示目录路径，确认其为当前部署实际使用的位置。不要直接通过资源管理器移动项目数据目录，除非项目维护流程明确支持该操作；路径变化可能导致记录不可访问。

## 常用路径

- 新建/选择项目：项目列表 → 项目操作。
- 查看记录：项目列表 → 项目详情 → 数据记录。
- 修改记录和受试者：记录行的更多操作 → 编辑记录信息。
- 开始采集或导入：项目详情顶部的对应按钮。
