# 数据回溯与波形浏览

## 打开记录

从项目详情的数据记录表选择状态允许回溯的记录，点击该行的波形/查看图标。列表中的两个回溯图标都打开记录回溯。若操作按钮不可用，先检查记录状态。回溯页面以当前记录为上下文；顶部工具栏可切换分析面板、查看事件和数据信息、导出信号。

打开后先看页面当前记录信息，确保记录名、通道数和采样率符合预期。切换到另一条数据时先返回项目详情，从目标记录重新打开，避免在上一条记录的画面中误以为已切换。

## 波形浏览常用操作

- 使用时间轴或定位控件移动到目标文件时间；读取时间时注意它是相对于整段记录的时间位置。
- 使用顶部的时间基控制每屏显示的时间范围，使用灵敏度控制纵向显示比例；这些参数改变显示尺度，不改变原始数据。
- 通过导联选择切换当前记录可用的信号视图。导入 EDF/BDF 记录只显示该记录自身随文件提供并通过校验的导联；纯 EDF/BDF 可能只有原始信号视图。
- 使用通道显隐或浏览控件聚焦感兴趣通道；切换通道显示不等同于删除或修改记录中的通道。
- 使用播放/暂停检查较长记录；可通过定位控件查看指定片段。
- 打开“事件列表”查看和定位事件；打开“数据信息”查看记录元数据。

页面顶部的高通、低通和陷波属于普通阅图的显示滤波设置。科学预处理对比使用独立的科学基线/结果预览，算法科学输入由科学预处理配置决定。改变阅图滤波不会改写源文件，也不能据此判断算法是否应用了相同设置。

### 按目标片段浏览

1. 使用时间轴或定位控件跳转到大致位置。
2. 调整时间基，让目标时间范围完整显示；放大观察时缩小每屏时长，浏览长记录时增大每屏时长。
3. 调整灵敏度以便看清波幅，但记录当前显示比例；改变灵敏度只改变绘图比例，不改变采样值。
4. 如需比较不同时间段，记下文件时间位置和窗口范围，再移动到另一段，保持相同时间基与灵敏度。
5. 如波形停止移动，先检查播放/暂停状态和记录是否到达边界；不要先把显示停止判断成信号缺失。

### 彩色波形、显示滤波与科学叠图

彩色波形是主要回溯视图，通道颜色用于帮助区分信号。顶部显示滤波参数控制普通阅图显示。科学预处理叠图用于对照科学基线和按当前策略处理后的波形；叠图与彩色波形用途不同，图例和状态文字应一起阅读。

如果叠图不可用，常见原因包括正在播放、切换到了在线临时导联、通道身份尚未保存、预处理输入发生变化或请求失败。此时界面会暂停/恢复科学对比或显示状态提示；先按提示返回稳定的分析导联、保存身份或重新确认处理，再重新加载叠图。不要将普通彩色波形当前滤波参数当成叠图科学参数。

## 事件标注

回溯页工具栏的“事件列表”用于查看已有事件并定位事件时间。打开列表后选择目标事件，检查波形游标跳转的位置是否符合事件标记。事件类型和快捷键由“设置”中的“事件设置”管理；改变事件定义前确认团队正在使用的命名和按键约定。

采集页面和回溯页面的事件能力受当前状态影响。若操作按钮不可用，检查是否处于正式记录状态、选中的事件定义是否已启用，以及当前页面是否支持该操作。不要把尚未写入记录的预览标记当成已保存事件。

## 运行回溯分析

回溯页“算法”菜单包含科学预处理、RBP、PSD、频段数值核查、自定义频段、STFT、FAA、IAPF、Theta/Beta、脑节律、个体化 BrainBeat 和 TNK 指标组等入口。实际可用性取决于记录通道、时间窗、采样率和算法输入要求。选择入口后，按面板提示确认通道、时间窗口与参数；不可用时先查看界面原因，不要通过随意切换无关导联绕过输入检查。

## 导出与记录信息

顶部工具栏提供“数据信息”和“导出”入口。导出会生成整段原始脑电信号 EDF/BDF，不会把屏幕显示滤波或科学预处理结果写回原始数据。导出格式与配套元数据说明见[EDF/BDF 导入与导出](edf-bdf-import-export.md)。

### 数据信息弹窗

使用顶部“数据信息”打开记录信息面板。核对记录名称、采样率、时长、通道数、来源和配置摘要；这些信息帮助确认打开的是预期记录，也便于排查分析输入问题。若显示的数据与项目列表不一致，关闭面板并重新从目标项目记录行打开。

### 回溯前后的推荐顺序

1. 打开记录后先核对元信息，不要先运行算法。
2. 切换到目标导联，并确认通道列表与预期记录相符。
3. 使用定位控件跳到实验感兴趣的文件时间，调整时间基和灵敏度以便观察。
4. 查看事件列表，确认事件位置与波形时间一致。
5. 决定是否配置科学预处理。若要比较处理效果，使用科学预览/叠图并确认状态与图例。
6. 最后进入分析面板，检查输入记录、信号、时间范围和参数，再运行分析。

## 回溯页面状态提示

- **加载/读取中**：等待窗口数据返回，不要快速重复切换导联或算法面板。
- **无波形/无数据**：确认记录状态、文件时间是否越界、当前通道是否有可用样本。
- **通道映射无效**：不要切到系统中另一个相似导联掩盖错误；检查文件随附映射或通道配置快照。
- **科学对比暂停**：先查看暂停理由，常见为播放中、临时在线导联或输入身份尚未保存；按状态文字恢复。
- **分析质量拒绝**：区分窗口拒收、输入不足与算法异常；查看算法质量信息，不要把拒绝状态解释成零值。
