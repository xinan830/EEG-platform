# 实时采集

## 进入采集准备

从“项目列表”打开目标项目，在项目详情点击“开始采集”。采集准备页会列出当前项目、设备状态、通道配置、导联配置、采样率、输入量程和受试者区域。先完成页面要求的检查；如果设备未连接、配置不兼容或必填条件未满足，“进入实时采集”不会启用。设备型号、厂商或序列号如果显示“SDK 未报告”，表示设备驱动没有提供该信息，不代表客户端检测到了一个具体值。

## 采集前检查

1. 确认放大器连接成功，设备信息与实际使用设备一致。
2. 选择本次实际接线对应的通道配置；核对启用状态、通道类型和电极映射。再选择与该设备和通道配置兼容的导联。
3. 从设备支持的采样率列表中选择实验方案要求的采样率。
4. 核对输入量程。页面若提供自动选择，确认设备返回的量程；要手动设置时，只从设备提供的合法选项中选择，不确定时先查设备/实验方案。
5. 按需选择已有受试者或创建受试者。编号和姓名可以不填；如果填写，确认没有选错项目或受试者。
6. 点击“进入实时采集”，进入实时采集页面。

通道映射和导联选择描述的是实际数据来源。若通道标签与设备接线不一致，后续波形标签、导联计算和分析对象都可能对应错误；不要仅为了让界面显示更多通道而启用未连接输入。

## 预览与记录

实时采集页顶部工具栏提供以下操作：

- **开始记录**：从预览状态进入记录状态并保存采集数据。开始后页面显示记录状态和采集指标。
- **暂停记录 / 恢复记录**：暂停的是记录保存；设备采集和实时波形继续。暂停期间未保存的样本会作为明确的数据缺口保留在审计记录中，因此恢复后记录时间轴不会把缺失样本伪装成连续实测数据。
- **完成记录**：结束当前记录并保存会话。完成前确认需要的事件标注和记录内容已处理。
- **阻抗检测**：检查物理电极接触状态。检测期间 EEG 采集停止、波形冻结；关闭检测窗口后客户端重新开始预览。开始记录后不能启动阻抗检测，需要先完成记录。
- **实时算法面板**：RBP、PSD、STFT 等入口在有实时数据流时读取数据；具体结果受通道、采样率和算法要求影响。预览期间的分析不等同于已保存记录上的离线分析。
- **数据信息**：查看当前记录与采集配置摘要。

事件标注工具在预览时用于准备观察；正式记录开始后才将事件写入记录。

不要将实时显示滤波参数误认为修改了原始记录。保存的数据和显示处理是不同路径；显示设置变化不会改写已保存数据。

### 按采集状态操作

| 当前状态 | 可进行的操作 | 预期行为 |
|---|---|---|
| 预览 | 开始记录、阻抗检测、查看实时算法 | 波形来自实时设备流；预览数据尚未存为正式记录 |
| 正在记录 | 暂停记录、完成记录、查看实时数据 | 样本写入当前记录；阻抗检测不可用 |
| 记录已暂停 | 恢复记录、完成记录 | 设备流和波形仍更新，但暂停期间没有样本写入记录 |
| 阻抗检测中 | 结束检测并预览 | EEG 流停止，阻抗窗口显示检测状态；退出后重新启动预览 |

### 阻抗检测步骤

1. 在预览状态点击“阻抗检测”。如页面弹出模式切换确认，阅读提示：检测时 EEG 预览和实时算法将结束，检测期间不采集 EEG。
2. 确认进入检测窗口，查看通道/电极列表和阻抗颜色范围。色带上限用于调整当前显示量程，不是改变硬件阻抗或电极状态。
3. 观察设备返回的检测值与状态；“等待设备上报阻抗”表示暂时没有读数，不要把空值当成通过。
4. 完成检测后点击“结束检测并预览”。等待 EEG 预览重新启动并确认波形更新。
5. 若退出后设备仍报警、预览不恢复或应用失去响应，停止继续切换并按[常见问题](../troubleshooting/common-issues.md)记录故障信息。

记录开始后阻抗按钮禁用，这是为了避免记录流和阻抗流同时争用设备。需要复测时，先完成当前记录，再回到预览模式。

### 暂停、恢复和完成的区别

- **暂停记录**只暂停样本保存，不暂停设备流。因此屏幕仍可能有波形，但它不代表暂停期间的数据已写入记录。
- **恢复记录**从恢复时继续保存后续样本；暂停区间会以缺口/审计信息表达，不能按连续采样处理。
- **完成记录**结束当前记录会话。若仍要继续采集，应按项目页面再次进入采集流程，避免把多个独立试次误合并为一个记录。

若实验方案要求暂停期间仍保留连续数据，不应使用“暂停记录”实现实验暂停；应根据设备与研究流程决定是否继续记录并另行标记事件。

### 事件标注

1. 进入事件标注工具，选择本次实验使用的事件类型。
2. 预览时可以熟悉工具和事件定义；只有正式记录期间执行的标注才会写入当前记录。
3. 触发实验事件时立即选择对应标记，避免事后凭记忆补时间。
4. 回溯记录时打开事件列表，确认事件类型和定位时间，再用事件定位跳转至对应波形。

事件类型和快捷键应由“设置” →“事件设置”统一维护。开始实验前先确认全体操作者使用相同事件名称和键位，避免同一任务被标成不同类别。

## 完成后确认

完成记录后返回项目详情，在记录列表核对记录名称、采集时间、时长、采样率、信号通道数、状态和受试者。只有状态允许回溯的记录才能打开数据回溯。若记录显示已中止或回溯按钮不可用，先查看状态和提示；不要把不完整记录当成完整采集。

## 注意事项

- 采集开始前核对通道映射、导联和采样率；错误的配置可能影响后续解释。
- 硬件量程应以设备能力和实验方案为准。
- 如果关闭阻抗检测后预览未恢复、设备状态异常或应用卡住，不要继续重复切换采集/阻抗模式；记录发生时间和界面提示并按[常见问题](../troubleshooting/common-issues.md)保留诊断信息。
