# EDF/BDF 导入与导出

## 导入到哪里

导入操作必须从目标项目详情页发起；成功后文件归属该项目，并显示在该项目的数据记录列表中。受试者关联为选填：可选已有受试者、创建新受试者，或不关联。导入后可从记录行的更多选项编辑记录名称及受试者信息。

导入不会因为文件本身包含某个受试者编号，就自动把它加入当前项目的人物列表；是否关联受试者由导入时的选择决定。需要管理受试者资料时，可在受试者选择区域创建/编辑；仅给记录改名不会修改 EDF/BDF 内部数据。

## 导入步骤

1. 打开目标项目详情。
2. 点击“导入 EDF/BDF”，在文件窗口选择 `.edf` 或 `.bdf` 文件。
3. 检查导入对话框中的文件名和文件摘要，确认选中的是目标文件。
4. 在“受试者（选填）”区域选择已有受试者、填写新受试者信息，或保持未关联；编号/姓名不要求必填。
5. 点击“开始导入”，等待文件读取、格式校验和记录创建结束；不要在处理中关闭应用。
6. 查看导入结果提示，回到当前项目详情的记录表，确认新增记录、通道数、采样率、时长和受试者信息，再打开回溯。

若导出时生成的配套元数据文件与 EDF/BDF 同源且映射通过校验，导入会恢复对应通道身份和导联快照；回溯时导联目录属于该记录。没有配套文件时，系统按 EDF/BDF 文件自身通道处理，平台自定义导联不一定存在。若配套文件损坏、索引重复或与信号列不匹配，导入会拒绝该绑定；不要把另一份记录的配套文件复制过来尝试绕过校验。

### 导入后逐项验收

| 检查项 | 在哪里看 | 通过时应确认什么 |
|---|---|---|
| 项目归属 | 发起导入的项目详情 | 记录出现在目标项目，而非仅在其他项目中搜索到同名文件 |
| 文件基本信息 | 记录表/数据信息 | 记录时长、采样率、通道数与源文件摘要相符 |
| 通道映射 | 回溯视图及通道标签 | 文件列与标签一一对应，没有重复、错位或未启用 EEG 通道混入 |
| 导联目录 | 回溯页的导联选择器 | 只显示此记录可用、随文件保存并通过校验的导联；无侧车时允许没有平台导联 |
| 分析可用性 | 回溯页算法面板 | 所选通道、窗口和算法输入满足条件，质量状态有说明 |

如果不确定配套文件是否同源，先复制到隔离的测试项目进行往返验证，不要覆盖原始文件或把一份侧车附到不同记录上。

## 导出整段信号

1. 打开记录回溯页面。
2. 点击顶部“导出”按钮。
3. 在保存窗口选择目标目录、文件名和 EDF 或 BDF 格式。
4. 等待导出完成；导出过程中按钮可用于取消当前导出。
5. 确认目标 EDF/BDF 文件及同目录配套元数据文件均已生成。需要保留通道映射和导联时，两类文件应一起归档、复制或传输，不能只保留其中一个。

按钮导出的是**整段原始脑电信号**，不是当前屏幕可见窗口，也不是应用科学预处理后的波形。页面显示滤波、坏导/坏段策略或 ICA 预览不会因此改写原始导出文件。

### 导出前检查

- 当前打开的是要导出的记录，标题/数据信息和项目归属正确。
- 记录可完整读取；若处于失败或中止状态，先查看状态，不要将部分记录误认为完整数据。
- 有足够的目标磁盘空间，保存路径符合本地数据管理要求。
- 若后续需要恢复通道名称、映射、导联配置或审计关系，确认随导出生成的配套文件也会被保存和传输。

导出过程中可通过按钮取消。取消后检查导出状态和目标目录，不要把部分生成的文件当成完整导出。再次导出时使用新的临时名称或确认旧文件状态，避免覆盖实验室唯一副本。

## 验证往返

推荐用匿名测试记录完整验收：导出 EDF/BDF 和配套文件 → 将两者一起放入测试目录 → 从测试项目导入 → 核对记录时长、采样率、通道数和映射名称 → 打开导联列表确认只出现本记录的随附导联 → 对同一时间窗运行同一算法，并核对输入与结果。仅看到“导入成功”或文件名相同不足以证明通道/导联闭环成功。

### 往返时需要保留的文件

把 EDF/BDF 和配套元数据视为一组文件：

1. 从回溯页导出到一个新建的测试目录。
2. 确认两类文件均存在且文件名/生成时间相符。
3. 复制或归档时整组复制，不要把配套文件单独改名、跨文件配对或重用到另一份数据。
4. 将这一组文件导入测试项目。
5. 若只需交换标准信号而不要求平台通道/导联信息，仍需确认接收方理解侧车缺失时可能无法恢复平台配置。

## 常见失败

- 文件格式不支持或文件损坏：确认文件能被其他 EDF/BDF 工具读取，再尝试重新导入。
- 通道配置索引重复/无效：检查随文件的通道元数据是否与当前文件对应；不要手工把旧侧车复制到另一份 EDF/BDF。
- 导入成功但导联少：确认原文件是否确实携带导联快照；纯 EDF/BDF 原始信号并不一定包含平台导联配置。
- 导出后重新导入失败：确认配套文件没有丢失，并且与信号文件同源。
- 记录已导入但列表不显示受试者：编辑该记录信息，确认是否明确关联了项目内受试者；仅文件内部文字不会自动创建受试者关系。
- 导入后的分析不可用：先确认实际 EEG 通道和导联是否可用，再确认采样率和分析窗口；“导入成功”只说明文件校验和记录创建成功，不代表每种算法输入条件都已满足。
