# 通道与导联配置

## 两类配置的区别

- **通道配置**描述设备实际输入的硬件通道、启用状态、通道类型和用户设置的电极/通道名称。
- **导联配置**描述从输入通道产生哪些分析/显示输出，以及参考方式或公式关系。

两者共同决定哪些通道能参与显示、回溯和算法。仅修改显示名称不能替代正确的物理通道映射；采集前应与实际接线核对。

内置设备、默认通道配置及系统导联统一显示为 **POP**。历史系统配置也按其固定身份显示 POP，原录音快照、通道映射及指纹保持原值；用户自己命名的配置按原名显示。驱动标识、SDK 文件名和硬件厂商来源属于技术身份，不随界面品牌改名。

## 配置入口

从左侧“设置”进入“通道配置”或“导联配置”卡片。两处列表支持搜索、筛选及查看已有配置；编辑前先确认列表中的设备型号、关联通道配置、参考方式和状态。通道配置页若未检测到设备，页面会提示先到采集页测试放大器连接，再选择设备读取其物理输入和默认电极模板。

建议先完成并保存通道配置，再创建或选择关联该通道配置的导联配置。采集准备页会根据当前设备和通道配置显示兼容导联；如果找不到预期配置，先回到设置检查配置归属和状态，不要通过选一个名称相似但输入不同的配置来绕过兼容性限制。

### 通道配置建议核对项

1. 启用状态是否与真实接入通道一致。
2. 每个硬件输入的通道类型是否正确。
3. 电极标签或用户映射名称是否准确，避免重复、空白或错误映射。
4. 保存后检查列表摘要，再进入采集准备确认当前选择。

### 创建/维护通道配置

1. 打开“设置” →“通道配置”。
2. 在通道配置列表中搜索或选择目标设备配置；若新建设备配置，按页面提示选择设备并载入物理输入。
3. 在编辑页逐行核对原生输入序号、启用状态、信号类型和电极标签。硬件通道序号对应物理输入，不要仅按界面顺序猜测。
4. 将未连接、未使用或非 EEG 输入按实际用途配置；不要把空电极标签或未启用输入误当成有效脑电通道。
5. 保存后回到列表，确认通道数量、启用数量和配置名称，再在采集准备页选中该配置做最终核对。

如果电极位置能在专用编辑页中维护，只有确认电极实际位置/帽型正确时才调整坐标。球面插值和地形图依赖电极位置，错误坐标会让空间结果失去意义。

### 导联配置建议核对项

1. 输入通道属于当前通道配置。
2. 每个输出导联所依赖的输入通道和参考关系正确。
3. 输出名称、顺序和有效性符合实验方案。
4. 在采集准备页确认导联与通道配置兼容。

### 创建/维护导联配置

1. 打开“设置” →“导联配置”，根据名称搜索已有配置，或点击“新建导联配置”。
2. 为导联配置选择关联的通道配置。关联关系决定可用输入，不是单纯备注。
3. 设置参考方式/参考通道，并在输出列表中逐项检查输入来源和输出导联名。
4. 检查每个输出需要的输入是否启用；如果某输出缺少任一输入，它可能在该记录下不可用。
5. 保存后回到配置列表，核对名称、关联通道配置、导联方式、输出导联数和当前状态。
6. 在采集准备页选择配置进行兼容性确认；在记录回溯页也要确认显示目录与预期一致。

修改一个已被项目使用的共享配置前，先评估它会影响哪些后续采集。对已经完成的记录，应以记录保存的通道/导联快照为准，不要假设修改全局配置会自动重写历史记录。

导联表达的是信号组合/参考关系。若导联依赖的输入通道未启用或缺失，该输出可能不可用；不要通过临时改名掩盖配置不匹配。

## 通道和导联的核对顺序

1. **先看输入**：这份记录真实采集/文件中有哪些原始通道，列顺序是什么。
2. **再看映射**：原生通道索引如何对应电极标签，启用状态和通道类型是否正确。
3. **最后看导联**：每个导联由哪些输入构成、使用什么参考，输出通道顺序是否符合预期。
4. **确认分析对象**：算法面板里的通道/导联是否来自当前记录的有效信号，而不是同名但不同来源的系统配置。

遇到通道数对不上时，不要先编辑导联补齐数量。先确认文件原始列、映射索引、启用投影和导联输入关系，这样能区分文件缺列、通道未启用、映射失配和导联依赖缺失。

## 典型信号配置示例

以下是理解配置的示意，不是适用于所有设备的固定模板：

| 层级 | 例子 | 需要确认 |
|---|---|---|
| 物理输入 | 设备输入 1、输入 2 | 导线实际接在哪个接口，硬件通道序号是否对应 |
| 通道身份 | 输入 1 映射为 Fp1，输入 2 映射为 Fp2 | 标签与帽型/电极位置对应；类型为 EEG、EOG、ECG 或其他实际类型 |
| 导联输出 | Fp1-REF、Fp2-REF、Fp1-Fp2 | 参考信号是否真实存在，输出公式依赖的输入是否启用 |
| 分析选择 | 对某个导联运行 PSD | 选择的是本记录可用的输出，窗口满足该算法要求 |

单极参考和双极导联输出的名称往往不同于输入电极名。例如 `F4-C4` 依赖 F4 与 C4 两路输入；如果 C4 被禁用或损坏，所有依赖 C4 的输出都可能不可用。分析时要检查导联公式依赖关系，不能仅按输出标签判断输入是否完整。

## 如何判断映射错误发生在哪一层

1. **物理通道数不符**：回到设备连接和设备输入清单，确认 SDK/硬件返回了多少物理通道。
2. **通道数正确但标签错**：检查通道配置中的原生索引和电极标签映射。
3. **原始通道正确但导联缺失**：检查导联配置关联的通道配置、参考方式和每个输出的输入依赖。
4. **回溯/导入记录与设置页不一致**：采集记录或导入记录可能使用自己的配置快照；检查该记录自身的通道/导联信息，而不是只看当前全局配置。
5. **算法输入比回溯显示少**：查看算法要求和启用 EEG 投影。显示视图中的通道不一定全部满足该算法的输入类型要求。

## 导入记录的范围

携带并通过校验的 EDF/BDF 通道配置与导联信息属于该导入记录。回溯该记录时使用其自身导联目录，不自动混入系统设备配置中的其他导联。无随附导联信息的文件可能只提供原始信号视图。
