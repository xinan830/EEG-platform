# 自定义 Montage 编辑器

## 变更原因

此前的“自定义双极”按照已选通道的顺序自动做相邻差分。通道选择顺序不是可靠的导联定义，用户也无法明确控制每条显示导联的名称、正极和负极。

## 行为契约

每条自定义导联使用结构化定义：

```json
{"name": "F3-Cz", "terms": [{"channel": "F3", "weight": 1}, {"channel": "Cz", "weight": -1}]}
```

后端按 `Y = sum(weight * channel)` 计算。名称必须非空且唯一；通道必须存在，权重必须是非零有限数，同一条导联不能重复使用同一通道。单个 Montage 最多 32 条导联，每条最多 32 个计算项。

同一份定义用于静态窗口、连续播放、调试采样和算法检验。算法检验返回实际公式，例如 `F3 - Cz`，便于追溯。

## 边界

本版本支持结构化线性表达式，例如 `F3 - 0.5*M1 - 0.5*M2`。它不解析或执行自由文本代码；用户通过通道和权重项构造公式，因此计算可以严格校验和审计。非线性函数不属于 Montage 定义范围。

通道数量只属于显示选择，不再提供所谓“标准 16/18/20 通道参考”伪 Montage。
