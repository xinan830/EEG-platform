# 独立导联验证器

新增 `backend/scripts/validate_montage_independent.py`，不导入项目 `app.services`，直接使用 MNE、NumPy 和 SciPy：

- 读取指定 BDF/EDF 和绝对时间点。
- 独立执行 0.5–70 Hz 带通与可选 50/60 Hz 陷波。
- 输出未滤波原始采样、独立滤波后的原始记录值和平均参考值。
- 平均参考明确使用文件全部 EEG 通道，并输出平均值。
- 支持 T3/T4/T5/T6 到 T7/T8/P7/P8 的名称兼容。
- `--synthetic` 模式使用已知数值验证平均参考和相邻双极公式，不依赖真实文件。

该工具与项目共享临床参数约定，但不复用项目实现代码；它用于交叉验证，不替代接口运行时调试。
