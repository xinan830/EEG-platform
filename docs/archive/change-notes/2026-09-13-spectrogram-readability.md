# Spectrogram readability improvements

- Reduced time-axis labels to approximately 5-second intervals and frequency labels to 1/4/8/13/20/30 Hz.
- Added subtle Delta/Theta/Alpha/Beta guide labels and boundary lines at 4/8/13 Hz.
- Added a numeric dB VisualMap colorbar using one P5–P95 range for the whole image.
- Added a neutral reading guide explaining that the current view is absolute power and that quantitative conclusions come from PSD, band power and RBP.
- Deliberately did not add automatic claims such as “alpha enhancement”: those require a defined baseline and statistical threshold and would otherwise be misleading.
