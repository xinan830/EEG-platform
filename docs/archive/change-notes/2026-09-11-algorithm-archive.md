# 算法分文件归档

## 变更内容

新增 `docs/algorithms/` 算法归档目录，将数据契约、显示滤波、Montage、频谱指标、实时/离线差异、验证方法和实现地图拆分为独立文档，并由 README 建立索引。

## 根因与证据

算法说明此前分散在源代码、工程契约和多条变更记录中，容易把显示滤波、实时分析和离线分析混为同一套算法。代码中已明确存在因果 SOS、零相位 SOS 和不同频段配置，因此必须分开记录。

## 影响

仅新增文档，不改变运行时代码、API、数据单位或算法参数。文档明确标注当前实现与待办缺口，避免将工程验证结果误解为临床结论。

## 验证

- 逐项对照 `waveform_filter.py`、`montage.py`、`spectral.py`、`offline_metrics.py`、`faa.py`。
- 检查新增文档未声称不存在的滤波器或临床认证。
- 未执行 `npm run build`；本变更不涉及前端构建。

## 可追溯性

归档入口：`docs/algorithms/README.md`。算法行为变更仍必须新增日期变更记录并同步测试与版本契约。
