# 删除按通道数量命名的 Montage 预设

## 事实与根因

- `standard_16`、`standard_18`、`standard_20` 只选择固定数量的通道，并对每个通道应用权重 `1.0`。
- 它们没有执行重参考或双极差分，数值上等价于“原始记录 + 固定通道选择”。
- 将这种显示选择命名为“参考”会混淆通道集合与 Montage 算法定义。

## 变更

- 从 Montage 目录和构建逻辑中删除三个通道数量预设。
- 16、18、20 或任意数量通道继续通过现有通道设置选择。
- 保留原始记录、平均参考、双乳突平均参考、任意单通道参考、Cz 参考、纵向双极、横向双极和自定义双极计算。
- 已保存的旧 `standard_*` ID 现在明确返回“不支持的导联方案”，不静默回退为原始记录。

## 验证与风险

- 后端测试验证目录不再暴露旧 ID，直接请求旧 ID 会失败。
- 不修改任何保留 Montage 的权重、公式、滤波或单位语义。
- 兼容性风险：依赖旧 ID 的客户端需要改用 `original` 并通过通道设置选择显示通道。
- `custom_bipolar` 已升级为结构化线性 Montage 编辑器，详见 `2026-09-11-custom-montage-editor.md`。双极差分是其 `+1/-1` 权重特例。
