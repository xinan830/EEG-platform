# 实时、显示与离线算法差异

项目目前存在三条有意区分的路径：

| 路径 | 滤波 | 主要用途 |
|---|---|---|
| 显示窗口 | `DisplaySignalFilter`，因果 SOS，0.5–70 默认 | 阅图波形 |
| 回放/旧实时分析 | `stream_filter.py` / processor，因果 SOS，指标默认 1–30 | 连续播放和实时指标 |
| 离线分析 | 4 阶 SOS `sosfiltfilt`，1–30 | PSD、IAPF、FAA、报告指标 |

因此同一绝对时间点在不同路径出现不同 µV 是预期现象，除非明确要求统一契约并完成迁移。当前不能把显示值直接当作离线指标黄金值。

参数变更必须重建因果滤波器状态。播放位置、固定页和视窗属于产品状态，不得从滤波器内部推断；是否定位或归零以当前调用动作的显式契约为准。

当前文件回放虽然视觉上是动态的，数据源仍是完整 BDF/EDF，因此动态 PSD 可复用整段 `sosfiltfilt` 后的缓存。未来接入真正实时采集时不能使用未来样本，必须建立单独的因果分析版本，不能继续标记为 `offline-spectral-v3`。
