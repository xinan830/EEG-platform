# 采集、回放与离线分析

项目已有 WPF 设备采集和原始记录，不应再描述为“硬件接入尚未开始”。设备 SDK 的读取、队列、原始写入和显示生命周期由桌面采集层管理，后端处理以有界批次或记录请求提供服务。

## 三种不同时间

- 采集时间来自有效样本计数与采样率，接收时钟只用于诊断。
- 回放游标是已保存记录内的位置，播放速度和显示刷新率不改变原始样本时间。
- 动态算法对记录中规划的窗口计算；按需由游标触发，仍属于离线记录分析。

“动态”不意味着设备流上的实时科学算法。当前官方 Brainbeat 是逐窗离线计算，不提供旧实时版本的跨窗 IAPF 锁定或 EMA。

暂停采集产生的缺口必须保留；回放和分析不能补造连续样本。后台全量完成、按需窗口可用和一帧波形发布也是不同事件，不应共用一个模糊“运行中”状态。

详见[窗口与运行策略](09-analysis-modes-and-time.md)和[采集/阅图状态所有权](../architecture/desktop-acquisition-review.md)。
