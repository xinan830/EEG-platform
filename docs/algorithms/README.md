## 版本原则

- 显示滤波与离线分析是两个不同算法契约，不能用一个版本号代替另一个。
- 原始 BDF/EDF 只读保存；滤波、参考和指标均产生派生数据。
- 逐点电压比较必须同时固定采样率、滤波器类型、阶数、相位、边界处理、参考和处理顺序。
- 当前验证状态是工程验证，尚未完成临床验证或医疗器械合规验证。
