# 波形播放与覆盖式扫屏

## 当前产品行为

播放采用“固定时间页 + 覆盖式扫屏”，不是连续滚动窗口。页面起点为：

```text
page_start = floor(current_time / screen_duration) × screen_duration
```

10 s 时间基下，7.3 s 属于 0–10 s 页，10.0 s 切到 10–20 s 页。上一屏/下一屏也使用相同固定边界。最后一页只对应文件真实剩余时间。

## 覆盖规则

进入新页时，上一页的画布像素可暂时留作视觉背景。当前页收到的真实样本从左向右覆盖对应位置，写入前沿之后保留 0.1 s 的白色擦除带，区分当前页新数据和旧像素。

旧像素没有当前页数据语义：不得用于时间轴、tooltip、测量、导出、事件定位或算法计算。Worker 只写服务器收到的真实样本，未来区域保持 NaN，不复制、不平移、不重标记旧采样点。

## 分页、缩放和暂停

- 播放头只在当前固定页内推进，到边界时换页。
- 暂停后时间和页面保持不动，Worker 收到的后台状态不得推动视图。
- 缩放后的 `viewDuration` 不超过当前时间基页面；平移被限制在当前页内部。
- 改变时间基会重新计算当前播放位置所属固定页。

## 性能策略

Worker 预分配最多 60 s 的有界缓冲，写满后保留后一半并移动缓冲起点。缓冲长度是性能实现，不决定用户看到的分页。绘制在 OffscreenCanvas 中完成，高密度数据按像素列保留最小/最大值，避免逐样本给主线程制造 DOM 或 Vue 更新。

频谱和时频图不从 Worker 画布取数据。它们只根据绝对时间向后端请求，因此擦除带、旧像素和缩放不会进入算法。
