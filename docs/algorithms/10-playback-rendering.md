# WPF 波形播放与分析游标

波形由 WPF/SciChart 呈现。采集实时显示与已完成记录阅图拥有独立的状态和缓存；当前实现不使用 Vue Worker、OffscreenCanvas 或 ECharts 播放链路。

实时显示消费有界批次，不能逐样本触发 UI 更新。阅图由目标位置驱动读取和派生帧发布，游标、请求轴与实际准备好的帧需要分别管理；冷目标允许短暂空白，不能将旧帧套在新时间标签下。

显示滤波状态、通道/导联选择、显示抽点和缓存都有明确身份。缓存损坏或参数变化不能静默沿用旧数据。原始缺口与生命周期边界必须保留，不能连接成看似连续的波形。

算法按需窗口可由游标触发，但其计算来自后端科学输入与窗口规划，不从已绘制曲线反算。阅图显示设置不自动修改算法的分析导联或滤波快照。

具体数据所有权、checkpoint、冷/热缓存、播放和硬件验收要求统一见[采集与阅图架构](../architecture/desktop-acquisition-review.md)，本页不再维护另一套渲染实施计划。
