# 数据契约与处理流水线

## 输入

- 文件格式：BDF/EDF，由 MNE 读取。
- 内部矩阵：`numpy.ndarray`，形状 `(samples, channels)`，浮点，单位 V。
- `sfreq` 单位 Hz；文件时长为 `sample_count / sfreq`。
- 通道名与矩阵列严格对应；匹配别名：`T3→T7`、`T4→T8`、`T5→P7`、`T6→P8`。

## 波形显示范围流水线

```text
BDF/EDF 原始数据 (V)
  → 读取所需通道和波形显示范围
  → DisplaySignalFilter（因果 SOS）
  → Montage 线性组合
  → V × 1e6
  → API 返回 values_uv / elapsed_s
```

显示接口的 `start_s` 是文件绝对时间。调试台输入的秒数也直接解释为文件绝对时间，不叠加当前视窗起点。

## 离线分析流水线

```text
原始数据 (V)
  → preprocess_offline（整段零相位 SOS 带通）
  → 分 epoch、坏 epoch 质控
  → Welch PSD
  → IAPF / 频段功率 / FAA / 比值指标
```

离线指标当前默认使用原始记录参考，不自动套用显示窗口的 Montage；调用方必须显式提供通道映射。

频谱 API 接受分析范围和通道列表；参考、滤波和 Welch 参数由 `offline-spectral-v3` 固定。

## 当前四类时间行为

| 路径 | 时间范围 | 更新方式 | 数学/显示用途 |
|---|---|---|---|
| 波形播放 | 固定波形显示范围 | 播放头推进，页边界切页 | 阅图显示 |
| 静态 PSD | 用户提交的 4–120 s 区间 | 区间提交或固定页变化时重算 | 稳定频谱摘要 |
| 动态 PSD | 最近 5/10/20/30 s | 播放中每 1/2/5 s 重算 | 观察近期频谱变化 |
| Spectrogram | 选定的 4–120 s 分析范围 | 每个 4 s 频谱计算片段以 1 s 步进形成时间 bin | 时间 × 频率变化 |

波形显示范围不是动态 PSD 的分析范围。两者可以同为 10 s，但属于独立配置。波形 Worker、擦除带、缩放和分页只改变展示，不改变后端分析输入。

## 单位与边界

- API 波形值统一为 µV，算法内部保持 V。
- 截止频率必须满足 `0 < low < high < sfreq/2`。
- 过短记录不能进行零相位滤波时必须返回结构化错误或质量失败，不能补零伪造。
- 滤波只影响派生结果，不覆盖原始文件。
