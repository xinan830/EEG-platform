# 验证、复现与黄金值

## 逐点验证所需快照

至少记录：文件标识、文件哈希（禁止提交真实 EEG）、采样率、通道顺序、绝对时间、取样索引规则、滤波器类型/阶数/相位/Q/边界、陷波、Montage 表达式、单位和算法版本。

## 推荐验证顺序

1. 用独立 Python 脚本读取 BDF，不调用项目 HTTP API。
2. 验证原始单位与通道名。
3. 独立实现或明确复用同一滤波契约。
4. 检查 Montage 线性组合；平均参考检查参与集合。
5. 比较多个通道和多个时间点，而不是单点。
6. 记录绝对误差、相对误差和滤波边界附近的差异。

## 必测不变量

- `original`：输出等于选定输入通道。
- 双极：输出等于正极减负极。
- 线性 Montage：逐项加权和与输出一致。
- AVG：所有参与通道的重参考值之和接近 0（浮点误差范围内）。
- 时间：`sample = floor(time_s * sfreq)` 的规则在所有接口一致。
- 单位：内部 V 与 API µV 只在边界转换一次。

## 当前缺口

真实 BDF 黄金值回归、长记录压力、多通道性能和跨库滤波一致性仍需补齐；现有测试主要覆盖纯函数、API 契约和工程行为。
