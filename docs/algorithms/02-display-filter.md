# 显示滤波与分析预处理

显示滤波用于按设置呈现波形，会改变显示样本数值；它不只是“美化”，也不自动决定算法输入。官方算法按自己的执行快照读取、投影和预处理原始记录。

## 显示处理

后端 `backend/app/services/waveform_filter.py` 提供因果显示滤波，维护 SOS 状态。参数包括带通、陷波和可选基线策略；实际数值以请求和返回契约为准。实时显示使用有界批次，阅图通过 checkpoint/连续重放维护其滤波历史，不以一个任意小的局部暖机窗代替完整状态。

WPF 拥有显示缓存和发布状态；Python 拥有信号滤波。不能为改善帧率在 C# 复制 IIR 科学实现。修改显示参数需失效相关派生缓存，旧请求不能覆盖新参数。

## 分析处理

共享离线频谱基线采用零相位处理；FAA 等模块有自己的配置与处理范围。连续滤波后切窗、逐窗滤波、因果滤波和不滤波不是等价操作，不能为了性能互换。详见[作者指南](official-algorithm-development.md)。

逐样本比较必须固定滤波器类型、阶数、截止频率、陷波、相位、初始状态、边界、处理顺序、导联和库版本。相同“1–30 Hz”标签不足以证明两次计算相同。

当前实时与阅图状态、限制及验证要求见[采集与阅图架构](../architecture/desktop-acquisition-review.md)。
