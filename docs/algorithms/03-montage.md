# Montage 与参考导联

实现位置：`backend/app/services/montage.py`。

## 统一数学模型

每条显示导联都是线性表达式：

```text
Y(t) = Σ(weightᵢ × channelᵢ(t))
```

权重是乘数，不是灵敏度或百分比。普通双极 `Fp1-Fp2` 等于 `1×Fp1 + (-1)×Fp2`。

## 记录级 Montage 服务预设

以下为后端通用 Montage 服务的类型，不等于 WPF 设置页的官方 ANT 配置目录。两者都必须以记录实际保存的源通道为依据。

- `original`：原始记录，不重参考。
- `average`：参与通道平均值；支持 `average_exclude`，可排除 Fp1/Fp2/F7/F8、坏道或非 EEG 通道。
- `linked_mastoids`：`通道 - (M1+M2)/2`。
- `reference:<channel>`：任意可用通道参考。
- `cz_reference`：Cz 参考。
- `longitudinal_bipolar`：标准纵向双极链（临床常称 double banana）。
- `transverse_bipolar`：横向双极链。
- `custom_bipolar`：结构化自定义线性表达式；名称沿用旧 ID，语义实际是 custom linear montage。

## 自定义表达式约束

请求结构为 `name + terms[]`，每项包含 `channel` 和非零有限 `weight`。后端逐项解析，不使用 `eval`，禁止重复通道、未知通道和空表达式。

## 参考范围

平均参考的参与集合由文件通道减去 `average_exclude` 得到，不是写死 21 通道。EOG、ECG、EMG 或坏道是否排除，必须由调用方配置并记录。

## 风险

不同通道集合会产生不同 AVG 数值；平均参考后的全部参与通道理论和接近 0，但显示子集本身不一定接近 0。

## 已完成记录的算法分析导联

算法详情中的“导联配置”和“分析导联”是两个独立选择器：

- “导联配置”默认选采集时配置，并合并基于记录保存的官方 ANT 通道快照生成的预设，以及兼容的当前用户 profile。官方预设不依赖用户目录是否已保存该条目；同 ID 的当前配置不能覆盖记录映射。候选由桌面端按记录采集快照筛选，并由后端再独立校验设备身份、完整 native 通道映射、REF/GND、公式依赖和 V 单位；不能只因设置中存在某导联就视为该记录可用。
- 当前兼容 profile 经后端验证后保存为独立、内容寻址的分析配置快照，并绑定 recording。算法详情展示采集历史目录和分析快照的来源；快照保存 profile 内容，不改变采集 manifest、chunk 或原始 EEG。后续修改当前设置不会改写已保存快照。
- “分析导联”由所选历史配置和算法声明的稳定输入角色共同生成。切换配置时保留角色，例如通道 1 从 `通道1-REF` 切到 `通道1-AV`；FAA、Brainbeat 等配对输入仍按各自角色和顺序映射。
- 算法请求携带所选配置身份、角色到输出映射、源通道映射和公式。后端从不可变原始采集通道投影信号，再交给算法自身计算；原始 manifest 和样本 chunk 不因切换而改写。
- 阅图页的显示导联只控制波形显示，不改变算法分析导联，也不触发算法 Run。

历史记录若缺少可验证的导联目录、源通道或所需角色，界面应显示结构化不可用原因并阻止 Run。不得保留另一配置的旧结果、按数组位置猜通道或静默回退到采集默认值。选择变化后，旧结果按配置修订标为过期或清除；新结果的 provenance 记录实际配置、分析输出、映射、公式、单位和范围。

旧记录若仅保存了有效的采集默认导联快照，可在重新注册时提交当前兼容 profile；后端校验通过后以独立快照提供备用分析配置。显式请求未保存或不属于该 recording 的分析配置时，读取层拒绝请求，不会改用默认导联。缺少默认快照或快照校验失败时，原始记录读取与导联分析分别处理，不能将原始通道冒充成有效的导联投影。
