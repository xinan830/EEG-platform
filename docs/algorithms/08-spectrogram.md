# STFT 与时频数据

STFT 属独立算法模块；通过 typed spectrogram 请求进入共享记录和预处理服务，不应把其输出当成 Welch 平均谱。参数、科学版本与输出声明由 `backend/app/algorithms/stft/` 提供。

## 执行边界

静态、全量动态和按需窗口共用 `stft/frame.py` 的一次科学源读取、坐标/矩阵校验、单位转换和质量证据。`runner.py` 与 `window.py` 只负责各自结果结构；调度准入、取消、缓存身份、持久化和发布仍由现有统一执行通道拥有，不新增 STFT 队列。

当前科学版本为 `spectrogram-v4-bounded-notch`，预处理版本为 `spectral-window-v1`，实现身份为 `stft-runtime-v7-bounded-notch`，窗口策略为 `stft-dynamic-window-v3-bounded`，Definition 为 1.1.0。v4 显式记录 1–50 Hz 默认基线和默认 50 Hz/Q=30 陷波；可通过算法设置关闭陷波。新执行不复用旧身份缓存，也不转换历史结果。

科学源只读取所选通道的目标区间和两侧有限滤波上下文；每侧上下文为 `max(2, 3 / low_hz)` 秒，向上取整到样本，遇录音边界截断。对该读取块执行原有陷波及四阶零相位 Butterworth 带通，再裁出目标样本；随后使用原有 Welch 总体质量门与 4 s STFT 内窗质量规则。目标区间或上下文含缺样则拒绝，不插值。TNK 继续使用其原有两秒上下文和科学身份。

例如低截止 1 Hz、目标 5 s，内部窗口最多读取 11 s 数据，录音开头/结尾更少；不等待整段科学缓存。显式请求很长的静态区间仍按所请求的区间处理，不能据此宣称任意请求都固定成本。

这是新的有限上下文科学契约，不保证与旧整段滤波逐点相同。相同源、配置、目标样本范围在静态、全量动态和按需路径间保持一致；不同外层区间即使相互重叠，边界不同也可能导致重叠部分数值不同。上下文长度是可复现策略，不是误差上界。

## 坐标与数组

时间、频率轴和矩阵形状必须一起读取。基础时频矩阵按时间与频率组织，动态外层还包含分析窗口；以输出声明和 artifact 轴元数据为准。时间中心、窗口起点、内部相对时间及录制绝对时间不能混用。

共享基础契约使用 4 s Hann 内部段、1 s 步长。若有效区间为 10–40 s 且采用该参数，完整内部窗为 10–14、11–15 至 36–40，共 27 行，中心为 12–38 s。可配置频率输出与预滤波分别声明；不能将这个示例当成所有请求固定 1–30 Hz。

## 数值与失败

线性功率与 dB 各带单位；`uV^2/Hz` 线性功率的 dB 表示为 `10*log10(P/(1 uV^2/Hz))`。不能对已经是 V²/Hz 的数组直接套用显示 dB 标尺。

同一预处理信号、样本、去均值、窗函数与归一化下，单个 FFT 行可以与相同单段 PSD 比较；Welch 多段平均与任意时频行通常不等价。

坏窗和缺样要保留真实坐标与状态，不删除时间轴后挪动后续窗口，不以零功率填补。JSON 中不可用值与 artifact 中非有限数组的表达分别服从结果契约。

静态结果可以保留质量合格的内部行，坏行显式为 NaN。动态外窗内只要有一行未通过质量门，该外窗整体拒绝：全量结果保留原槽位并填 NaN，按需结果返回失败和证据、不返回矩阵。源数据结构不合法则标为不可用。两种动态策略使用一致的失败语义，后续好窗独立计算。

预热阶段，按需结果仅含实际完整内部段；全量结果为固定三维形状补 NaN，不能把补齐部分视为已计算数据。线性结果固定为 V²/Hz，dB 结果固定为 dB re 1 µV²/Hz。

## WPF 消费

WPF 只投影后端数组、时间与质量证据。完整 Run 窗口若缺少当前内部时间轴或有限上下文预处理范围证据，返回 `FULL_WINDOW_CONTRACT_UNAVAILABLE`，要求重新计算，不补造 provenance。预处理证据记录目标/读取样本范围、上下文长度、零相位、边界截断、单位 V、通道顺序与缺样拒绝策略。色标、缩放和显示抽点不改变科学数组。详见[结果指南](official-algorithm-development.md)。
