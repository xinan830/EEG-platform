# 频谱模式与时频窗统一

## 变更

- 静态 PSD 继续使用 30 秒外层分析窗口，随阅图窗口起点变化刷新。
- 新增动态 PSD 模式：播放时每秒更新一次最近 10 秒窗口，暂停时保留当前结果。
- 动态模式与静态模式共享 `offline-spectral-v3` Welch 契约（4 秒 Hann 分段、50% 重叠）。
- 时频图统一为 4 秒 Hann 窗、1 秒步进，并在 API 元数据中返回 `segment_s=4`。

## 影响

`10 秒/屏` 仅控制波形阅图窗口，不再决定静态 PSD 的长度；动态 PSD 的窗口和刷新策略在频谱面板中明确显示。

动态更新采用保留上一结果的增量显示：请求新窗口期间继续显示上一条曲线和功率表，仅显示“正在更新数据”状态；请求完成后替换数据，避免整个面板闪烁或被加载占位内容重建。

动态请求采用串行队列：后端计算超过 1 秒时不并发取消旧请求，只保留最新滚动窗口，当前请求结束后立即处理最新窗口，保证播放位置不会因为请求延迟而停滞。

频谱面板新增 Chart.js 频段占比图。图表按通道显示 Delta、Theta、Alpha、Beta 的 RBP 百分比，数据直接来自 `relative_band_power` API 字段；前端不重复执行频谱计算。

频谱算法校验弹窗新增模式、动态窗口、刷新步长、Welch Hann 窗、频率范围、参考方式和算法版本说明；当前通道展示逐频段积分与 RBP 结果，全部通道表格展示四频段绝对功率和占比。
