# 2026-09-10 通道选择与波形回放同步

## 用户行为

- 阅图工具栏新增“通道设置”。用户可在文件原始通道列表中全选、清空或勾选任意非空集合。
- 确认后，静态阅图窗口立即以选择结果重读文件 `0.0 s`；如正在播放，旧会话先停止，再从 `0.0 s` 创建新显示。
- 绘图层不再将已选通道再次裁剪为默认五通道。通道轨道与 API 返回的数据列顺序一致。

## 契约变更

- `POST /api/recordings/{recording_id}/waveform-playback` 可在创建会话时提交 `{"channels":["Fz","Pz"]}`；服务端在读取首帧前固定选择，避免默认五通道首帧。
- `POST /api/waveform-playback/{session_id}/control` 新增动作 `set_channels`，请求体为 `{"action":"set_channels","channels":["Fz","Pz"]}`，供未来不重建会话的交互使用。
- `channels` 必须为非空字符串数组。后端大小写不敏感匹配，返回和展示始终使用文件原始通道名。
- 选择顺序由界面按文件原始通道顺序提交，后端保留请求顺序；通道改变会重建滤波器并强制回到文件 `0.0 s`。

## 风险与验证

- 初始通道在创建会话 API 内确定，因此首条 WebSocket `info` 已是选择结果；不会短暂退回默认五通道。
- 显示全部 21 通道会降低每条轨道的垂直空间，属于用户明确选择后的可见代价；没有设置五通道的隐式上限。
- 本次新增组件和 composable，未新增超过 400 行的源文件；`App.vue` 通过抽取通道选择状态与停止会话帮助函数控制规模。
- 前端几何测试同步为“满量程保留轨道安全边距”的现行渲染契约；此前测试断言的是 2026-09-10 早些时候已被替换的旧映射比例。
