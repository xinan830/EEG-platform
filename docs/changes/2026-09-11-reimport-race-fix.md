# 重复导入修复

## 问题

第一次文件的窗口请求或导联元数据请求可能晚于第二个文件完成，旧响应会覆盖新文件状态，导致第二个文件需要刷新后才显示波形。

## 修复

- 文件代次与窗口请求代次分离。
- 重新导入或新建会话时，旧文件的异步成功和失败响应都会失效。
- 波形画布的滚轮监听改为显式非 passive，保留 `preventDefault` 的缩放行为并消除浏览器 Violation 警告。
- 波形画布节点在空状态和有数据状态之间不再销毁重建，避免 Worker 继续绑定已脱离 DOM 的旧 OffscreenCanvas。
- 算法检验结果增加当前导联的正式名称，和时间、滤波参数一起显示。

## 验证

- 新增双文件连续导入回归测试。
- 前端相关测试 4/4 通过，TypeScript 检查通过，文件行数门禁通过。
