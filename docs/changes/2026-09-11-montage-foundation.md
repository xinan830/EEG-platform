# 导联设置基础版

## 变更

- 新增后端 `montage` 模块，以结构化线性项定义导联，不依赖数组下标。
- 静态窗口和连续 WebSocket 回放共用同一套导联推导。
- 新增原始记录（不重参考）、平均参考、双乳突平均参考、纵向双极、横向双极、Cz 参考、标准 16/18/20 通道参考和自定义双极方案。
- 支持 `T3/T4/T5/T6` 到 `T7/T8/P7/P8` 的兼容解析。
- 新增 `GET /api/recordings/{recording_id}/montages`，报告预设是否因缺失电极不可用。
- 窗口接口和回放创建接口新增 `montage` 参数，同时保留旧 `reference` 参数兼容。
- 前端新增导联选择条，并维护原始通道选择与导联输出通道的分离状态。
- 移除重复的显示预设下拉框，新增算法检验弹窗；可按文件绝对时间查看导联公式和处理后 µV 值。

## 行为约束

- 缺失电极时返回明确错误或禁用预设，不生成部分伪装的临床导联。
- 导联计算只作用于读取副本，不修改原始 BDF/EDF 数据。
- 纵向和横向双极、Cz 参考及标准通道方案都要求完整必要电极；Laplacian 和加权自定义表达式留待后续变更。

## 验证

- 后端：34 个测试通过。
- 前端：`vue-tsc --noEmit` 和 21 个 Vitest 测试通过。
- 文件行数检查通过，生产源码仍保持单文件不超过 400 行。
