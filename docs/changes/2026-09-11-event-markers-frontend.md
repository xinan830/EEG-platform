# 人工事件标记前端闭环

## 变更

- `WaveformPanel` 在时间轴上显示当前窗口内的事件标记线。
- 新增事件控件：使用文件绝对时间创建、跳转到事件和删除事件。
- `useEventMarkers` 按当前 recording 重新加载事件，导入第二个文件时不会复用上一个文件的标记。
- 事件创建、删除仍通过后端 API 持久化，失败信息写入共享错误提示。
- 旧分析视图中的历史事件转换为只读标记模型，保持组件类型统一。

## 边界

- 时间轴事件线只显示落在当前可视窗口内的标记；事件数据本身不会被窗口裁剪。
- 当前没有用户身份、角色权限、签名、哈希链或防篡改存储，不能视为临床合规审计。
- 文件删除与事件级联清理策略仍待生命周期设计。
