# 回放非预加载读取

## 变更

- 新增 `RecordingService.open_data_reader()`，回放使用 MNE 非预加载 Raw 读取器。
- 回放每次只读取当前 50 ms 所需的源通道；Montage 计算仍在内存副本上完成。
- 拖动定位的滤波预热也按块读取，不再复制整份记录数组。
- 离线分析继续使用原有 `load_data()`，保持其完整数组接口不变。

## 结果与边界

- 长文件和全通道回放的内存占用不再随文件总样本数线性增长。
- BDF/EDF 随机读取仍有磁盘和 MNE 解码开销；真实文件压测和多用户并发基准尚未完成。
- 静态窗口检查点缓存与回放读取器是两条独立路径，均受同一滤波契约约束。

## 验证

- `test_waveform_session_reads_raw_data_in_display_chunks` 验证每次读取不超过一个 50 ms 块且关闭 Raw 资源。
- 后端全量测试：42 个通过。
