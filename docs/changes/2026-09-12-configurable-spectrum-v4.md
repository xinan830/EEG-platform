# 可配置频谱分析 v4

## 完成内容

- 冻结 `offline-spectral-v3`，新增 `offline-spectral-v4-configurable` 安全配置层。
- 新增 `POST /api/recordings/{recording_id}/spectrum/configured` 和统一请求 Schema。
- 开放静态自定义时间范围、动态 5/10/20/30 秒窗口、1/2/5 秒刷新和通道顺序配置。
- 静态越界明确拒绝；动态播放初期返回 warm-up 状态，至少积累 4 秒后计算。
- 响应返回请求配置、实际执行配置、v3 基线版本和 12 位配置指纹。
- 响应顶层同步返回请求/实际起止时间、窗口时长和 warm-up，调用方无需解析嵌套配置即可判断是否裁剪。
- 波形区新增频谱区间框选模式，4 秒以上选区自动送入静态 PSD。
- 算法校验同步展示执行模式、请求窗口、刷新步长、基线算法、配置指纹和逐通道频段明细。
- 增加配置模型边界测试：动态安全选项、最小/最大分析区间和重复通道均有明确验证。
- 动态窗口/刷新控件显示实际数值；静态分析范围校验失败时在面板内明确提示，不再静默忽略。
- 时频图增加 configured API，统一返回请求/实际区间和配置指纹。
- 修复静态范围输入显示浮点长小数、文件时长异步更新不同步及频谱接口错误信息被吞的问题。
- 框选区间统一保留 3 位小数，并在提交前按文件时长和最小 4 秒规则校验。
- 越界拒绝错误现在包含文件实际结束时间，便于定位元数据与选区差异。
- 静态区间边界按采样周期容差校验，允许界面毫秒四舍五入造成的单采样点误差，仍拒绝实质性越界。
- 静态频谱区分“跟随当前屏幕”和“锁定自定义区间”：默认/快捷范围随阅图换屏更新，用户提交自定义范围后保持锁定。

## 验证

默认 v4 配置与 v3 的 PSD、绝对频段功率和 RBP 逐项一致。前端不执行 FFT、频段积分或 RBP 计算。
