# 连续 EEG 波形回放设计

## 目标

导入 BDF/EDF 后，以原桌面程序一致的方式显示波形：50ms 连续采样块、连续去直流与 50Hz 陷波/1–30Hz 带通、十秒扫屏缓冲、固定微伏标尺和可暂停/重播/定位的时间轴。

## 边界

本次仅处理波形回放。IAPF、指标计算和通道映射分析继续使用现有播放服务，不作为此改动的依赖。波形回放可在导入后直接使用，不要求先保存分析映射。

## 数据流

FastAPI 为每个录制创建独立的 `WaveformPlaybackSession`。会话读取 BDF/EDF，选择 Fz、Pz、Oz/O2/O1、F3、F4（缺失时以文件前八个通道补足），每 50ms 读取一个原始 chunk，并在服务器保持 DC、陷波和带通滤波状态。WebSocket 只发送已滤波的 chunk（µV），不发送完整十秒窗口。

Vue 端以 `WaveformSweepBuffer` 保存固定十秒的 Float64Array 环形缓冲。新 chunk 在扫描指针处写入，扫描头前方 0.2 秒置空。Canvas 只画有限值，NaN 产生断线。每条通道采用真实 µV 加固定通道间距，而不按通道自动归一化。

## 错误与交互

创建/流式回放错误显示为现有错误提示。暂停、继续、重播和定位使用会话控制 API；重播与定位都会重置滤波器和前端扫屏缓冲，防止旧状态混入新位置。
