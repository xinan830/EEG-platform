# Design

Build per-resolution label/native indexes that retain all matches so duplicate bindings still fail. Reuse a validated source mapping for repeated CAR dependencies; do not add a persistent metadata cache or bypass source checks. Move review composition/cleanup from the nearly full MainWindow file into its review partial by responsibility. Show the bound review window before initialization, reject duplicate opens during metadata loading, and clean up initialization failures without closing a replacement session. Report source loading before each chunk rather than leaving the preceding filter status visible.

Verify high-density resolution with a deterministic field-lookup budget, malformed duplicate/native/type/unit bindings, existing raw/import/montage/geometry tests, desktop startup/loading/cancellation tests, and timings on the actual imported recording. Rendering and hardware behavior require explicit manual acceptance.

The actual imported CAR sidecar contains its complete channel binding and formulas but omits optional desktop-saved fingerprints. Deserialize snapshots through one review boundary: validate required identity, channel/formula structure, device and reference fields before any catalogue deduplication; derive missing channel and montage fingerprints with the existing canonical hash functions. Preserve explicit source fingerprints and the persisted source JSON. Never substitute an empty fingerprint or alter samples. Invalid snapshots stay unavailable with a diagnostic reason. Log foreground read/navigation exceptions with recording/session/generation and absolute target seconds, without EEG samples. Verify primary and catalogue-only minimal snapshots, malformed fields, display cache identity, real-file initial frame and navigation, and in-session cached redisplay. No database/source migration; rollback only reverts code.
