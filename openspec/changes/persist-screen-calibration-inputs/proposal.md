## Why

屏幕实际宽度和高度是走纸速度、时间基换算的本地显示偏好。当前用户输入后只有显式保存才写入，而且恢复依赖当前显示器识别键；用户重新启动软件后容易看到空输入框并误以为校准丢失，导致换算回退到名义比例。

## What Changes

- 对有效的宽度、高度输入提供可靠的本地持久化，并在下次启动时恢复。
- 保存校准文件时使用原子替换，避免进程退出或写入中断留下半截配置。
- 当前显示器识别键发生变化时，优先恢复同一校准文件中的最近有效配置，并继续保留按显示器保存的精确配置。
- 无效或不完整输入不覆盖上一次有效校准。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop/live-waveform-display`: 屏幕物理校准输入必须跨应用重启持久化，并在缺少精确显示器键时安全恢复。

## Impact

- 影响 WPF 桌面端的屏幕校准 ViewModel 和本地配置存储，不改变 EEG 原始数据、样本计数、通道顺序或后端 API。
- 配置文件仍属于当前 Windows 用户的 LocalApplicationData；旧格式 JSON 继续可读。
- 回滚可删除新增的恢复逻辑并保留现有配置文件；科学计算和采集流程不受影响。
