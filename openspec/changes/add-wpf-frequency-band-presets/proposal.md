# Add WPF frequency-band presets

## Why

Peak Frequency and Band Ratio already accept explicit frequency boundaries, but
manual Hz entry makes standard Theta, Alpha, and Beta analyses unnecessarily
error-prone.

## Scope

Add WPF-only presets that populate the existing numeric inputs. The final
numeric values remain the scientific request and are submitted unchanged to
the backend. IAPF and the official Theta/Beta algorithm retain their fixed
scientific definitions.
