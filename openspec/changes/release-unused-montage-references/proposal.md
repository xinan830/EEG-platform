# 删除失效引用后的导联预设

## 原因

旧引用索引只保存曾使用过的导联 ID，并永久累加。最后一份采集记录
彻底删除后，导联依然无法删除。归档状态本身不是根因。

## 范围

- 分离历史版本锁与现存记录引用；曾引用版本仍不可覆盖，但没有现存
  引用时可删除预设。
- 现存引用包含活动项目记录、回收目录记录、曾登记项目目录及外部记录。
- 新采集与回溯登记记录位置；持久化扫描来源，移除项目不代表删除数据。
- 升级旧 ID 数组，扫描可发现记录后释放孤立的删除禁令，不清空历史锁。
- 缺失磁盘、读取失败、损坏 manifest 或无法定位的新引用均保持保护。

不自动删除用户记录、回收目录或导联，不改 EEG、历史快照、参考公式、
通道 ID 筛选及算法来源。

## 限制

旧 ID 数组没有记录位置，无法找回未登记项目之外的旧外部文件；迁移只
对平台可发现范围核实引用。移动文件到全新外部位置需要重新打开/登记。
目录扫描与创建同步限于一个桌面进程，不承诺跨进程文件事务。

## 验证

测试活动记录、回收目录、多记录、彻底删除、重启、旧数组迁移、项目移除、
外部记录、损坏元数据、创建期间并发删除及创建失败。运行导联/采集测试、
Release 构建、OpenSpec 严格校验与差异检查；用户真实数据仅只读核实。
