## ADDED Requirements

### Requirement: Layout preset menus use an anchored dropdown presentation

Acquisition and recording review SHALL render layout preset menus with the shared white, rounded dropdown presentation. Opening a menu SHALL anchor it to the lower edge of its layout button rather than to the pointer or a desktop-default location. The menu MAY shift within the available work area to remain visible while staying attached to its trigger.

#### Scenario: Open a layout preset menu

- **WHEN** the user opens the layout preset menu in acquisition or recording review
- **THEN** it uses the shared white background, rounded border, compact typography, and highlighted menu-item treatment
- **AND** its placement is relative to the layout button
- **AND** all existing layout choices remain available
