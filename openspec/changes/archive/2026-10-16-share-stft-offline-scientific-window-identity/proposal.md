# Why

PSD 的全量/按需窗口复用已经通过真实记录验收。STFT 也有两条离线执行路径，但当前按需窗口与全量动态序列的内层时间坐标和暖机矩阵形状没有明确统一，不能直接共享数值窗口。

# What Changes

- 明确 STFT 动态窗口的内层时间轴为相对于外层窗口起点的秒数。
- 仅允许科学身份一致且为完整窗口、固定内层矩阵形状的按需 STFT 结果被全量分析复用。
- 缺少、损坏、坐标/形状/单位不符或 Partial 窗口由同一个 STFT 模块重新计算。
- 复用与重新计算都保留完整 Run artifact、窗口状态和执行 provenance。

# Impact

涉及 STFT 按需窗口输出契约、全量动态矩阵组装、离线窗口复用能力声明和契约测试。不修改 STFT 的 Welch/时频数学、滤波公式、单位或原始记录，不接入实时分析；PSD 和其他算法的已验收行为不变。
