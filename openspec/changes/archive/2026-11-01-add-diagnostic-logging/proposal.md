# Proposal

为采集、回溯和算法运行建立统一的诊断日志链路。当前项目已有 HTTP 控制台日志、SQLite 操作审计和采集目录中的 `audit.jsonl`，但它们没有统一落盘、没有覆盖 WPF 请求链路，分析 worker 的异常也缺少完整 traceback，现场问题难以复现。

本变更增加：

- 后端按日期滚动的诊断日志文件；
- Run 排队、执行、窗口进度、完成、取消和失败阶段日志；
- WPF 按日期滚动的客户端日志文件；
- WPF HTTP 请求生成并发送 `X-Request-ID`，同时记录请求结果；
- 未处理异常、后端启动失败和关键采集诊断的统一记录入口。

本变更不改变 EEG 算法、原始 recording 格式、Run 状态语义或用户可见数值，也不把原始样本、完整本机路径、患者信息、令牌或密码写入普通诊断日志。
