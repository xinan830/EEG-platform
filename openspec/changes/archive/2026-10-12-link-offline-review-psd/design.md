# 离线回溯算法联动设计与执行计划

## 1. 范围和完成边界

状态：P0-P2 已有实现；P3 联动正在收口，P4-P5 未完成。自动化测试不代替真实 GUI 验收。基线：752ea3d。

第一版在现有 WPF 回溯中接入一个动态 PSD 面板；复用播放、暂停、拖动、
倍速和事件跳转，不新建回溯页面，不改变现有波形样式。
默认不开启分析；点击唯一“PSD 分析”入口打开右侧面板并加载参数，点击“应用并分析”准备结果。
参数和 SciChart 图表由独立 PsdReviewAnalysisPanel 管理布局，回溯视图只组合左右两栏。
回溯工具栏是高通/低通/陷波参数的唯一编辑入口；PSD 在“应用并分析”时捕获这些值，
仍由后端读取原始记录计算，不读取显示波形。沿用当前回溯默认值 1/30/50 Hz，不偷偷改成 PSD 旧默认值。
顶部菜单为项目、分析、报告、设置；尚未实现的报告/设置入口禁用。
分析 → 分析区间 → 分析窗口长度使用后端 PSD policy 选项，改变当前工作区设置，不改变历史 Run。
公共窗口状态由 ReviewAnalysisSettings 持有；PSD 仅拥有源通道与算法版本/步长契约。
参数变更立即隐藏旧谱，保留历史 Run 身份与回溯游标；显式应用后才准备新结果。
晚到的旧进度、结果与错误按配置修订丢弃，不能将旧结果重新绑定。
左右两区初始等宽，GridSplitter 调整比例，关闭面板恢复完整波形区域；同一页面重新打开保留比例。
“停靠 / 分离”将同一个面板移入独立可移动、可调整尺寸的 WPF Window。
关闭小窗恢复停靠；关闭面板保留 Run 和游标；页面卸载关闭附属窗口。
当前分离通过按钮触发，不实现跨宿主拖动自动脱离/吸附停靠。
关闭面板后回溯仍可独立使用，后端不可用不阻止原始波形回溯。

本次不接采集流，不做多算法同时分析，不分析显示导联合成通道，
不改变 PSD 科学定义，也不全面重构全部算法。
RBP/STFT/其他算法是后续独立接入阶段，不能以 PSD 完成代表全部完成。

## 4. 四类状态必须分离

1. 回溯状态：唯一 PositionSeconds、播放状态、倍速、目标及已呈现波形。
2. 请求配置：记录、源通道、高低通、陷波、动态窗口和步长，带 configuration_revision。
3. 科学结果：不可变 Run、源 hash、版本、artifact 和质量证据。
4. 展示状态：请求游标、实际结果窗口、图表选择、提示和缓存。

通道/科学参数改变保留回溯位置，产生新配置版本；旧请求不能覆盖新配置。
记录变化重新绑定并按现有回溯策略复位；不得复用上一记录结果。
查看导联、灵敏度、纸速、缩放只影响波形显示，不自动改变分析通道/参数。

## 5. 时间与窗口选择契约

- 时间使用记录起点相对秒，不使用系统当前时间、视口局部坐标或 GPU 帧计数。
- 原始计数器 c 对应相对样本 s = c - first_sample_counter，t = s / sfreq。
- 联动比较以 int64 的 RecordingRelativeSampleIndex 为权威坐标；秒是传输兼容和显示值，
  不要求本次迁移全部旧数据库/API。sample index 保留 gap 占据的时间位置，不是有效样本的紧密序号。
  计数器重置/溢出必须由已验证的记录映射处理；无法映射时明确失败，不能直接相减猜测。
- 秒游标转相对样本边界采用 floor(t * sfreq)，验证有限值并限制在 [0, duration_samples]。
  两端使用相同映射，不加可提前一个样本的浮点容差；整数游标优先直接传输，转换边界纳入 P0 测试。
- 窗口统一为半开区间 [start_sample, end_sample)，同时返回明确单位的秒坐标。
- 后端生成分析窗口与取整规则；WPF 不重新生成科学窗口。
- 按后端窗口索引选择 end_sample <= cursor_sample 的最近一个窗口，整数边界比较。
- 映射仅返回一个 window_id/index；索引按 end_sample 单调排序并校验唯一性。
  不按窗口中心最近距离或“游标属于哪些重叠区间”选择；重复/损坏索引明确失败。
- 不向前四舍五入，不跨越被拒绝窗口去寻找更早的有效谱替代当前结果。
- 例如后端 5 秒窗口、1 秒步长，游标 17.4 秒匹配结束于 17 秒的窗口；
  必须展示该窗口实际范围，而不是声称计算到 17.4 秒。
- 第一完整窗口前显示数据不足与所需窗口长度；Partial 仅按后端政策展示并显式标识。
- 拖回早期时间时，趋势和结果也退回该时间，不留下未来窗口。
- 超过末尾、落在 gap、窗口拒绝、没有结果分别保留独立原因和实际窗口。
- 尾部不足一个步长不由 UI 补造窗口；已有后端计划未生成尾窗时展示最后实际窗口及覆盖终点，
  明确剩余尾段没有新结果。Partial 是否存在由保存的窗口与官方政策决定，不由展示层另定。

第一版展示的是既有离线零相位结果。结束时间限制只约束窗口选择，
不保证滤波未利用未来样本。UI/溯源明确标识 offline + zero_phase。
有界结果读取绝不改变 Run 的预处理上下文：不得为一次读取重新取 4/5 秒 EEG 并单窗 filtfilt。
连续预处理、gap 分段和边界策略沿用 Run 已记录的科学契约；修改它们需要独立科学变更。
若以后要求实时等价，单独定义因果滤波状态、延迟和 checkpoint，验证差异再接入。

## 6. 请求、计算与交互

1. 从回溯记录上下文自动注册 completed 记录，绑定后端 ID/hash/通道表。
   同目录重复操作不反复注册；路径不是科学身份，身份以服务返回为准。
2. 用户打开面板：验证参数，按后端 catalog 初始化选项，选择真实唯一源 EEG 通道。
3. 通过 EnsureAnalysisRun 语义解析配置：兼容且完整的 completed Run 直接复用；
   queued/running Run 订阅已有进度；不存在匹配项时才创建。取消或执行失败允许显式重试。
   第一版会话内复用必须实现；跨会话解析由后端权威身份与权限/项目边界决定，
   P0 固定新增解析接口或兼容查询方案，不使用只查最近若干条 Run 的前端扫描保证全量复用。
4. 未命中时提交一次动态 Run，沿用窗口级进度、取消和后端配置去重。
   第一版等 Run 完成后显示科学结果，不假称已有逐窗口增量发布接口。
5. 结果准备期间波形照常回溯；显示算法准备进度而不是阻塞回溯。
6. 完成后根据当前回溯游标读取最近窗口，不回到最初提交时的游标。
7. 播放、暂停、倍速、拖动、事件跳转只选取结果，不生成新科学 Run。
8. 通道/科学参数编辑合并最后有效配置；无效输入不提交，不抹除旧 Run 身份。
   旧结果隐藏或明确标为旧配置，不当成新通道当前结果。
9. 暂停后修改通道仍在当前时间自动展示新结果；不自动恢复播放。
10. 关闭/切记录取消订阅、等待和结果读请求；不删除历史结果。
    已共享的后端 Run 不因一个面板关闭而盲目取消。用户主动取消通过现有取消契约执行。

高频游标更新合并为 latest-only，只有窗口索引变化或配置变化才读取。
缓存命中直接投影；最多一个前台结果读取，邻窗预取有界并让位前台。
任何回调都验证 recording_id、configuration_revision、run_id、target_revision。
保留现有拖动期间节流加载的连续反馈，不改为只在鼠标松开后读数据。
轨道点击仍沿用目标完整帧提交语义；算法读请求跟随最新被接受目标，不从 MouseMove 或 VisibleRangeChanged 直接发起。
缓存未命中同一窗口的在途读取可复用；目标真正改变时取消旧等待并限制并发，不将每一帧排队。

### 配置身份与 Run 复用

科学指纹由后端规范化配置与身份生成，至少包含源 hash/坐标基准、分析范围、
有序源通道、真正参与分析的参考/变换、预处理/质量政策、窗口/步长、算法参数、
科学版本、实现身份及已有缓存契约要求的环境字段。
查看导联、波形滤波状态/显示数组、倍速、当前游标、主题、图表模式不进入科学指纹。
共享的高低通与陷波参数值在应用时进入科学配置及指纹；显示与离线计算相位语义仍各自保留。
本次不引入显示导联合成输入；不能为复用忽略源或版本变化。

configuration_revision 是本地竞态保护，不是科学指纹；request_id 是请求身份，
idempotency_key 是一次提交的重发身份，均不能与长期配置身份混用。
相同配置失败后重试使用新请求身份，避免永久幂等键一直指向已取消 Run。
完成 Run 的复用必须校验结果可读与完整性；损坏结果明确报错，用户可显式新建 Run，不能静默展示残留。
科学质量拒绝并不等于任务执行失败：已完成 Run 中的 Rejected/Unavailable 窗口可如实复用，
同配置反复重算不能作为消除质量拒绝的策略。
复用保留原 run_id 及来源；后端既有 completed cache 的结果复用和直接复用 Run 身份要区分。
共享 Run 的取消权限和归属遵守原项目边界，原 CreateRun 的审计行为不因 Ensure 入口被全局改变。

## 7. 波形与算法同步呈现

唯一游标不意味着波形和算法都瞬时准备完成。
保留目标时间、已呈现波形范围、已呈现算法窗口三者，不能用同名时间掩盖加载延迟。
波形旧帧保留沿用现有策略；新算法窗口未就绪时显示加载/待同步，
上一算法结果不得标为当前目标结果。已请求窗口返回后原子替换图表、单位、质量和溯源。
后端故障、损坏 artifact、拒绝窗口均不停止波形时钟，也不使用旧有效数据填空。

## 8. 有界结果接口和长记录

建议只读窗口接口：GET /api/runs/{run_id}/window-preview?cursor_sample=...。
cursor_sample 使用记录相对样本边界；若保留 cursor_s 兼容输入，由后端按统一策略转换。
不同时接受两个冲突坐标；响应回显解析后的样本坐标及派生秒。这里不是运行中增量发布接口。
实施阶段固定正式字段和错误码，保留原 structured-preview 不变。
响应包含 Run/源身份、请求游标、实际窗口索引与样本/秒范围、状态、质量/失败详情、
轴及数组单位、频段占比、算法/实现版本、预处理相位和 artifact 完整性标识。
无匹配窗口返回明确无数据状态，拒绝窗口保留 null 与原因，不返回伪零。
接口中的“原始结果”指保存的 PSD 数值，不是原始 EEG samples。
不返回波形数组，不复用显示滤波数据当分析输入；波形保持原 Playback Reader 链路。

PSD 一次仅取一个窗口的谱与后端频段占比；显示历史若需要，再增加有界分页，
不默认下载整条记录的所有矩阵。对端点速率、cell/byte、缓存、并发规定可配置上限，
数值需经短记录/小时级记录压测后定，不在计划中把未经测量的预算当承诺。

当前压缩 NPZ 不等于可按窗口随机读取。先选择版本化索引/分块或派生 mmap sidecar，
在后端 artifact 层实现有界转换/读取、原子发布与完整性关联。
禁止完整 np.load 后切片冒充内存有界。旧 NPZ 保持可读与可导出；
旧 Run 初次建立可重建索引时显示准备状态，不覆写原文件或重算 PSD。
hour-scale 测试必须测转换峰值内存、临时磁盘和冷读成本。

## 9. 可追溯与可修正

每次已呈现结果携带以下诊断快照：

- review_session_id、recording_id、后端 source_sha256 和时间映射基准。
- configuration_revision、配置指纹、run_id、algorithm_id、scientific_version、implementation_identity。
- 通道原始标识/stream_index、分析参考、滤波与 notch、窗口/步长。
- requested_cursor、实际窗口索引、start/end sample 和秒、窗口状态及单位。
- observed/threshold 等原始质量证据、稳定错误码、request_id、读取耗时与缓存命中。
- artifact 身份与完整性、离线/相位语义；版本化诊断格式便于后续纠错。

按窗口/状态变化记录，不逐样本打印，不在普通日志写病人姓名、完整本机路径或 EEG 数组。
错误可复制诊断信息，保留中文可读原因；不根据英文错误文本分支。
修正通过新实现身份和新 Run 产生新证据，旧 Run 永不原地修改。
源 fingerprint 当前可能包括 audit，需核对人工事件编辑后的身份策略；
不能为增加缓存命中静默省略已有 fingerprint 字段。

## 10. 中央接入清单与规模纪律

预计中央改动仅包含：

- 回溯 View/ViewModel 组合入口和卸载入口。
- 算法 API/Contracts 的窗口读取及模块展示能力接口。
- PSD 展示 DTO/投影提取；旧详情页继续绑定同一实现。
- 一个 PSD provider 注册入口。
- 后端结果 router/service 和 artifact-window reader 组合。
- EnsureRun 的权威解析接入点（若 P0 判定需要新增），单列契约和项目/权限边界，不改变所有旧提交入口。

后端官方算法注册/公式无需新增分支；不改采集循环/擦除带，不重写播放控制器。
每阶段记录实际文件和原因；清单增长时先评估缺失扩展点，不在中央文件追加算法特判。
新增文件目标 <=400 行；已有大型 ViewModel 只做组合，新增行为放独立职责模块。
所有超过策略阈值的变更必须完成职责评估，不以扩大登记上限替代结构设计。

## 13. 风险、回滚和决策门

主要成本是冷 Run 等待、压缩 artifact 的随机访问改造，以及展示入口解耦，
不是仅在回溯页面添加一张图。第一版可先等待完整计算，不承诺边算边显示。
冷远跳还可能等待波形因果滤波历史准备，这是原回溯成本，不混入 PSD 准备进度。

若要求严格无未来样本、使用合成导联做算法输入或运行中逐窗发布，
必须先新增对应科学/接口变更，不能在此计划里默许。
若未能验证有界读取和旧 Run 兼容，不放宽限制强行交付长记录。
时间和复用契约明确不等于后续实现没有风险；NPZ 转换内存/磁盘、并发取消、
历史身份校验和冷读延迟都必须以 P1/P4 实测作为进入交付的依据。

回滚通过关闭联动入口恢复原回溯，不删除原始数据/Run/artifact；
窗口 API 为新增接口，旧详情接口保留。派生索引可重建，不作为唯一科学来源。
