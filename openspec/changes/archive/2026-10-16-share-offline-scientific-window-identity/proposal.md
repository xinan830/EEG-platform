# Why

全量 Run 与按需 Session 的缓存身份分别维护，Definition 摘要和采集导联证据的纳入方式不同。PSD 同窗口已存在数值比较测试，但完整 Run 不能利用已完成的按需窗口。

# What Changes

- 明确两种离线执行方式 `full` / `on_demand`，通过原有各自 API 执行。
- 共用科学身份快照与窗口键，覆盖源数据、采样率、算法/Definition/实现、参数、导联映射、滤波、质量与窗口契约；执行方式、重试代数和显示状态不改变科学身份。
- PSD 全量分析按窗口复用同项目内校验通过的按需结果，缺失窗口调用相同模块计算。其他算法继续既有执行路径。
- 历史 Run/窗口不回填猜测的科学身份、不重写 artifact；完整分析仍产生独立完整 artifact。

# Impact

涉及后端身份模型、已有 JSON 快照与 provenance 的增量持久化、PSD 动态窗口适配与契约测试；复用现有数据库字段，schema 保持 v19，不新增迁移。不修改滤波公式、V/float64 单位、记录相对半开样本范围和 WPF 参数布局。实时分析不在范围内。
