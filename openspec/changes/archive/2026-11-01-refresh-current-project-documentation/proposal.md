## Why

当前代码已采用 WPF + Python 后端、九算法模块和统一执行边界，文档仍混有已删除 Vue 客户端、退役公式执行器、旧实验开关和过时审计进度。用户要求保留最新说明，删除旧稿和错误内容。

## What Changes

- 更新根入口、交接、工程契约、文档导航和当前能力路线图。
- 依据实际代码整理数据读取、导联、预处理、算法模块和结果追溯说明。
- 删除旧变更笔记、重复调研、已完成实施草案和失效架构说明；Git 保留删除前版本。
- 保留 OpenSpec 决策记录、带日期的验证证据及冻结 JSON/NPZ；明确其适用版本，不将旧测试数或旧验收结论改写成当前结论。
- 修复引用；为主规范中的历史 shadow/浏览器工作台条款补充被后续规范取代的状态导航；删除只断言被删除历史文档字句的过时测试，不改变生产行为。

## Capabilities

无用户行为或科学契约变更。纯文档整理，`skip_specs: true`，不生成 delta spec。

## Impact

范围为 Markdown/文本说明、OpenSpec 上下文及一个历史文案断言测试。时间、单位、有序通道、API/WebSocket、滤波、算法公式、原始记录和 Run/artifact 均不变。不增加历史兼容逻辑。主规范仅添加历史适用状态和后续规范链接，不改写 requirement/scenario；未解决的规范与代码差异须显式列出，不能靠修改说明掩盖。

无需数据库或接口迁移。删除文件可从 Git 恢复；回滚为还原本变更文档。验证包括链接、代码路径、冻结件 checksum、针对性架构测试、OpenSpec strict 和 diff 检查，无需重跑全部科学套件。
