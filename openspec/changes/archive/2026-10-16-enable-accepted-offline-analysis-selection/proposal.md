# 直接在界面选择离线分析方式

## Why

九个算法已逐项获得用户验收反馈，Review 综合和后端故障场景也已获用户确认。现有“执行方式”下拉框仍受默认关闭的启动开关限制，导致用户必须反复输入成对环境变量。

## What Changes

- 已验收的 PSD、STFT、RBP、频段功率比、频段峰频率、IAPF、Theta/Beta、FAA、Brainbeat 在各自模块内声明默认开放按需能力。
- 复用动态参数中的“分析方式”下拉框，默认全量，用户可选择按需；两条路径继续使用原有 API 和科学模块。
- 前后端保留每算法环境变量作为维护覆盖：未配置时采用模块声明，`0` 显式关闭，`1` 显式开启。未来未声明默认开放的模块仍默认关闭。
- 源码启动脚本不再强制设置 PSD 的验收变量；双击后直接使用当前源码和界面选择。

## Impact

涉及后端模块可用性声明和启动筛选、WPF 结果处理器与共享可用性解析、现有下拉框、启动说明及测试。科学公式、滤波、单位、窗口、质量、缓存身份、原始文件和历史 artifact 不变；不新增实时模式或数据库迁移。Review PSD 适配器复用相同可用性规则。

## Validation and rollback

验证无环境变量时九模块提供两种选项、全量仍默认、显式关闭后回退完整路径、真实下拉框双向绑定、模式切换清理旧窗口，并执行前后端回归、Release build、OpenSpec strict 和文件规模检查。紧急回退可成对设置对应变量为 `0`；不删除历史结果。
