# Design

The new official RBP version uses the original recording reference, zero-phase fourth-order Butterworth 1–50 Hz bandpass, 50 Hz notch (Q=30), and the existing four-second Hann Welch / two-second overlap quality contract. It requires sampling frequency above 100 Hz. Frequency grid and PSD density remain in Hz and V²/Hz; each band is boundary-interpolated and trapezoid-integrated to V², then converted to µV² for evidence. The five band powers are normalized by their sum, not by an independently integrated total that may differ at the boundaries. The 50 Hz notch is part of this frozen version because it matches the platform's current spectral-analysis default; it attenuates the Gamma band near its 50 Hz upper edge. Gamma therefore describes the output of this declared preprocessing pipeline, not an unfiltered 30–50 Hz spectrum, and the notch must remain visible in the Run provenance.

Bands: Delta 1–4, Theta 4–8, Alpha 8–13, Beta 13–30, Gamma 30–50 Hz. Adjacent boundaries are shared only as integration endpoints, with zero-width overlap. Static and every dynamic window use the same computation and null-on-failure rule. Dynamic scheduling is unchanged.

The scientific version and implementation identity change, and a 2.0.1 platform Definition is published alongside the immutable 1.0.0 Definition. A 2.0.0 draft was already published locally during development before its preprocessing metadata was completed; it is preserved rather than rewritten. New Runs resolve 2.0.1, and startup verifies that its digest matches the code-owned draft. Stored old Runs are not recomputed or rewritten. WPF chooses four- or five-band labels from the Run's scientific version and only renders returned values.
