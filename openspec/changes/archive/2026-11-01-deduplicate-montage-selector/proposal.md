# 导联选择器去重

## 原因

采集准备页的导联下拉框会把相同稳定身份的系统预设重复显示。系统预设和
持久化导联在刷新时被直接合并，旧版本或重复来源会产生多套相同名称的
REF、平均参考、M1/M2、Cz、纵向双极和横向双极选项。

## 变更

- 在导联目录汇合处先按稳定导联 ID 去重，再识别旧版本产生的重复系统预设语义身份。
- 系统预设先加入，遇到同 ID 或同一系统预设语义的旧持久化条目时保留当前系统预设。
- 只对完整匹配系统预设语义的旧条目去重；同名但导联规则不同的用户配置仍保留。
- 采集记录和 TNK 算法页复用同一目录规则，并过滤历史快照中重复的信号投影。

## 不变

原始采样、通道顺序、导联公式、记录快照、历史引用锁定和导联 ID 语义不变。
