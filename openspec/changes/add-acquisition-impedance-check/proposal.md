# Proposal

## Why

操作员需要在正式录制前，以及发现电极接触异常后，读取真实电极阻抗并定位需要调整的物理电极。目前平台已有 EEG 采集和电极布局能力，但没有阻抗检测入口及其设备生命周期。

## What Changes

- 电极位置窗增加第三项“地形图”，复用黑点电极样式及现有位置，不生成虚假功率或阻抗插值；修正共享3D视图Shift拖拽平移反向。

- 增加独立阻抗检测模式：开始、实时读取、单电极选择、结束并进入 EEG 预览。一个放大器在 EEG 与阻抗模式之间互斥切换。
- 使用现有头型和所选采集配置的物理电极坐标，显示逐电极阻抗图及可排序列表；通道设置与阻抗检测共用圆圈内电极名称的公共样式，算法地形图保持原有黑点样式。内部 Ω、界面 kΩ，采用可编辑数值节点及颜色的连续渐变色标，缺测与异常明确区分。
- 预览中切换会结束当前 EEG 会话；录制中或录制暂停时必须由用户明确确认结束并成功保存当前记录，才允许检测；检测后重新录制创建新记录。
- 复用现有设备会话及配置运行时作为唯一设备模式入口，纳入检测中、切换中、失败清理、取消、断连和后台探测互斥。
- 阻抗检测仅依据采集配置映射物理电极；不改变现有导联设置、波形展示或算法输入行为。

## Capabilities

### New Capabilities
- `desktop/acquisition-impedance`: 真实硬件阻抗测量、物理电极映射、检测交互、单位与质量状态，以及安全切回 EEG。

### Modified Capabilities
- `desktop/device-session`: 共享设备状态明确表达 EEG/阻抗占用与模式切换，阻抗运行或清理期间禁止后台枚举、重配和再次开流。
- `desktop/ant-eego-adapter`: 原生独占流约束覆盖 EEG 和阻抗两种模式，释放顺序与已有 EEG 行为保持一致。

## Impact

- 桌面设备契约、ANT 原生接口/适配器、配置运行时、设备会话、采集准备与工作区入口、电极图呈现及对应测试。新增内部显式阻抗契约，不复用要求 SampleCounter 的 EEG 批次。
- 不新增 Python 科学公式、后端 API/WebSocket 消息、数据库迁移、原始文件格式或第三方依赖。阻抗不进入 EEG 写盘、滤波、算法或回溯。设备测量值由 SDK 提供，桌面只格式化和按明确色标映射。
- 非目标：边录制边检测、跨阻抗间隔续接同一 EEG 文件、阻抗历史/报告、自动判定医学合格、改造既有导联行为或算法图表。呈现整改仅涉及通道设置与导联示意图的公共命名圆圈；导联箭头避让圆圈边缘，投影与业务语义不变。
- 兼容性：扩展可选设备能力；无阻抗能力的驱动保持 EEG 功能，显示明确不支持。现有记录、导联库和回溯行为不变。
- 迁移：本变更只规划和实现阻抗检测，不依赖其他功能变更的完成或归档。实施前核对共享文件的最新差异并保留无关工作。无需数据迁移；回退时关闭并释放阻抗模式后撤回本功能，不改已有数据。
- SDK 依据：本地 `Ant SDK` 的 SDK 手册第 13–14 页声明单活动流、阻抗为最新状态且单位 Ω。实际更新周期、异常返回及 REF/GND 能力仍须真机验证；UI 读取周期不等于硬件刷新周期。
