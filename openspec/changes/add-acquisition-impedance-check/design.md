# Design

## Context

动机见 proposal.md。当前 WPF/.NET 10 桌面已有：

- `ConfiguredAcquisitionRuntime` 的 transition 串行边界，拥有设备适配器和 EEG `AcquisitionCoordinator`。
- `DeviceSessionManager` 的唯一设备事实快照及 `DeviceSessionAvailabilityMonitor` 的后台探测。现有忙碌判断只识别 EEG 生命周期，必须扩展覆盖阻抗。
- `AntEegoNativeRuntime` 的进程级流租约与原生调用串行锁，EEG 适配器使用真实流通道表。
- `ElectrodeMapProjection`、`ScalpMapRenderer`、保存的通道快照和独立硬件 REF/GND 位置。

SDK 手册 `UDO-SM-0124 rev8.1` 第 13–14 页：两个流不能同时活动；阻抗 GetData 是最新状态，一次一个样本，单位 Ω，不遵循 EEG 积累与每秒取数要求。仅按主机读取时间判断通信新鲜度，不能声称 SDK 提供了测量时间或更新频率。

## Goals / Non-Goals

**Goals:** 在现有设备所有权下增加阻抗模式，保持原始记录与算法的科学边界；检测具体物理电极，安全返回全新的 EEG 预览会话。

**Non-Goals:** 新建平台级总协调器、改动后端公式和回溯、跨检测间隔续写同一文件、模拟测量或插值填充阻抗头皮区域。

## Decisions

### 1. 生命周期唯一入口，阻抗只拥有自己的读取会话

复用 `ConfiguredAcquisitionRuntime` 的 transition 作为跨 EEG/阻抗模式的唯一入口，增加只读的类型化设备模式快照及事件，供 `DeviceSessionManager` 统一发布。细粒度状态表达 Idle、Opening/Closing、Eeg、Impedance、Faulted；EEG 自身 Previewing/Recording/Paused 状态继续由原协调器拥有，不建立两个可独立写入的 busy 标志。

独立小型 `ImpedanceSession` 仅管理阻抗流、取消与快照发布，不拥有第二套设备发现、重配或选中设备状态。EEG 数据仍归原采集协调器。

所有 discovery/configure/open/stop/dispose 路径在同一运行时边界重新检查模式；设备会话的提前检查只用于交互，不作为安全保障。禁止锁内调用再次获取同一个 transition 的公共方法；采用已有内部操作路径，保持单一锁顺序，覆盖与 refreshGate 的竞态测试。原生调用锁只围住单次 SDK 操作，不能在等待 UI、计时器、写盘或整个检测周期时持有。

替代：让弹窗直接 new 适配器或新增独立设备协调器，会绕过现有设备占用与后台探测，所以不采用。

### 2. 可选阻抗能力与独立测量契约

在 Devices/Contracts 增加可选阻抗能力与流接口，避免要求不支持它的设备驱动实现虚假方法。能力初始为 `Unknown`；成功打开真实阻抗流才能证明 `Supported`，只有驱动明确返回时才能标记 `Unsupported`。不能根据 DLL 存在推断硬件支持，也不能把普通 SDK 错误转成“不支持”。未知能力通过一次受控开流尝试探明；角色和 native index 作为一个物理通道身份传递，不能只传 index。

ANT 绑定 `eemagine_sdk_open_impedance_stream`，复用现有 native lease、取流通道表、prefetch/get_data 和结构化错误处理，增加独立阻抗流实现。输入通道依据 SDK 与手册支持的物理角色选择，禁止照搬 EEG 的全通道清单或默认包含双极、触发、计数器。真实输出次序以打开后的 SDK 通道表为准。

契约包括 detection_session_id、设备标识、native role/index、stream index、有值时的 resistance_ohms、读取时间 received_at_utc、递增的本地主机更新序号和有效性状态。读取次数不是设备样本计数；不引入 EEG sampling rate、SampleCounter 或 EEG scientific seconds。UI 对有效 Ω 值除以 1000，显示 kΩ。

负值、NaN、Infinity、缺失和厂商明确的无效标记不作为正常阻抗；不猜测未说明的数值哨兵。启动真机验证时核实断线/开路的实际返回并留证；确认前不能承诺识别所有开路状态。

替代：扩展 AcquisitionBatch 兼容无采样计数器的状态值，会污染 EEG 科学时间和单位契约，所以不采用。

### 3. 安全模式切换与数据分段

| 来源 | 进入阻抗的顺序 | 取消/失败 |
|---|---|---|
| Idle/已停止且设备有效 | 校验配置、占用设备、打开阻抗 | 清理后显示失败 |
| Previewing | 提示切换、结束预览及分析、关闭 EEG、打开阻抗 | 不自动恢复旧 EEG 会话；提供重试/预览动作 |
| Recording/Paused | 阻抗入口禁用，运行时拒绝请求 | 当前 EEG 与录制保持不变 |
| Opening/Closing/Impedance | 拒绝重复或不兼容动作 | 单个检测窗获得焦点，不创建第二会话 |
| Faulted/原生占用不明 | 先处理错误及释放 | 未确认释放不能开流 |

确认对话框显示当前 recording/session 身份；返回确认后在生命周期锁内再次核对，防止过期确认误结束后来创建的记录。复用现有 stop/finalize 公共行为并确认其错误会传回上层，不以单纯 state=Stopped 当作写盘成功。

“结束检测”只回到已连接空闲状态；若工具窗是从预览打开，点击窗口关闭按钮会先停止读取、关闭流/放大器并释放租约，再以已验证采集配置新建 EEG 预览。“结束检测并预览”始终执行同样的返回预览操作；离开工作区时只清理检测并保持空闲。预览所需项目、采样率或保存导联不完整时，显示准备问题并保持空闲。绝不自动开始录制。

新 EEG 会话使用新的标识和采样起点，滤波器、原始滚动缓存和实时算法窗口不继承检测前数据；旧请求以现有会话/revision fencing 失效。先前记录保持原样，下一次录制另建记录。

预览来源的阻抗切换在 UI 侧额外冻结最后一屏的显示样本和擦除带位置。新预览启动后，只把这段有界历史与新会话映射到同一个显示坐标；新会话首样本显式断开线段，之后新数据按自身真实计数前进。该显示投影不更改 `AcquisitionBatch` 的原始样本，也不进入写盘、滤波输入或实时算法。阻抗期间没有 EEG，显示时间轴暂停而不按阻抗持续时长推进；因此它是视觉接续，不代表真实连续采样。采样率或物理流布局不兼容时放弃合并并显示新会话。

### 4. 轮询、线程与清理

首版使用后台顺序异步循环，每次读取后等待500 ms（成功和空读均节流），不重叠读取，不为每个电极开任务。该周期是软件取最新状态的频率，最终依据真机开销验证；不承诺硬件 2 Hz 刷新。一次发布不可变最新快照，UI Dispatcher 只接收当前 session 的最新值。测量不依赖 Python 服务是否在线。

UI 保留最后一次成功通信的单调时间；重复的相同数值也算成功通信，超过3秒未收到成功状态则标灰并显示过期。保留数值仅用于诊断，同时显示最后接收时间，不强行中断仍在执行的原生调用。

取消读取后等待原生调用退出，再按 stream → amplifier → lease 顺序释放；清理幂等，失败保留占用/故障信息。不能用 Task 超时后卸载仍被原生调用使用的 DLL。驱动不支持中断的原生调用时，超时后提示仍在停止并禁止新流，直至调用返回或重启。关闭窗、离开工作区、断连与退出应用共用该清理路径。

### 5. 独立工具窗与逐电极呈现

使用与现有采集界面一致的 WPF owned 非模态工具窗，支持移动；打开一次、再次点击聚焦。读取持续到显式结束、关窗、离开采集工作区或错误。阻抗测量期间采集控件明确显示 EEG 未运行，原波形不伪装成实时刷新。

布局：顶部设备与检测状态；左侧较大头皮图；右侧电极列表及选中项详情；底部阈值图例与结束/进入预览。保持原有蓝色动作样式，绿黄红仅用于测量状态；同时提供数值、文字、键盘选择和可访问名称。复用头型几何和坐标来源，增加阻抗专用小控件；不修改已有算法图表，不复用功率地形插值，不把依赖编辑草稿的控件直接绑到测量层。

物理映射键是 native role/index → 已选采集配置的物理通道快照中的电极名/位置，检测开始时冻结。预览进入时使用该会话的采集配置快照；空闲进入使用已验证的采集准备配置。映射只描述实际物理电极，不读取显示或算法侧的派生通道。REF/GND 位置只来自操作员已有配置；位置未知放独立角色区，不使用可视控件默认位置冒充实际位置。无位置电极仍列出 native index 与可用名称。列表默认按有效阻抗降序，异常项单独突出；选中项保持物理键稳定，刷新不抢焦点。

2026-11-23 用户确认的呈现整改：共享圆圈电极控件统一绘制圈内名称、选中描边及可选的圈上读数，通道位置图与阻抗图引用它；位置投影与手动坐标不变，算法地形图继续采用原有黑点，不改其渲染与色标。

阻抗色标采用三项可编辑 kΩ 节点及对应颜色，作用域仅本次检测，不新增偏好存储。最低节点初始为0，其余数值留空；满足0 ≤ 最低 < 中间 < 最高且三种颜色有效才启用连续RGB渐变。节点之间线性映射，范围外饱和为端点颜色，真实读数不截断；图下显示同一映射的渐变条、三个刻度与单位。默认配色绿→黄→红，可复用现有颜色选择器修改；不预设未经验证的医学合格线。无效配置保持数值和中性色，缺测、无效和过期读数显示灰色与原因，不对头皮区域进行阻抗插值。

## Risks / Trade-offs

2026-11-23 第三视图与3D平移：电极位置窗采用互斥的2D、3D、地形图状态；地形图复用同一位置控件与公共黑点画法，仅只读呈现位置及名称，不构造科学结果或色标。2D继续允许草稿拖拽，3D保持标准坐标与原加载入口。共享3D平移原先使用Up×Look得到屏幕左向量，误作右向量；改为WPF右手系Look×Up，垂直方向使用Right×Look，沿正确相机平面反向移动相机，使屏幕中的头模跟随指针。补充多朝向投影断言及上下左右拖拽回归。时间、单位、采样、API、存储及3D电极坐标不变。

2026-11-23 电极位置窗细化：按用户最新要求保留标题与全部说明文字，打开时默认最大化，只有位置编辑图的头型比例从0.39增至0.46，绘制/命中/拖拽共用几何。REF默认示意点由(0.0036,0.4514)调整至(0.0036,0.62)，避开Pz；新默认与旧默认值均在通道图和阻抗图按新点显示，旧配置不自动改写，其他自定义位置保持原样。标准EEG坐标、采样时间、单位、通道序、API/WebSocket及文件格式不变。

- [录制数据丢失/隐性断档] → finalize 成功后再切换，用户确认，新记录分段；检测期间没有 EEG。
- [后台枚举抢占 SDK] → 所有调用在统一模式所有权下重新检查，测试定时探测/重配/开流竞态。
- [通道类型与顺序差异] → 独立阻抗契约，按 SDK 实际表和 native identity 映射，真机验证 REF/GND、开路及双极支持。
- [SDK 关闭/读取卡住] → 不提前释放租约或卸载库；故障阻止新流并保留诊断。
- [颜色被误读为临床合格] → 数值、单位、操作阈值与无效状态共同显示，不内置缺乏证据的合格线。
- [共享大文件继续膨胀] → 新增职责所有者而非追加整套逻辑到现有大 VM/协调器；修改前重新统计。现有约 843 行的 AcquisitionCoordinator 和约 1199 行的 AcquisitionWorkspaceViewModel 需分别按高风险/超过千行规则评审，在 docs/code-size-policy.json 登记可执行拆分计划或经明确审查的例外，不能仅 mechanically 拆分 partial 文件。

## Migration Plan

1. 规划已单独提交；实施只接入阻抗检测，保留其他任务的工作区改动，不提交 SDK 厂商包。
2. 实施先做设备/测量契约与假设备测试，再接真实 ANT 流；采集入口与生命周期按本变更独立实现，并在动共享文件前核对最新差异。
3. 最后合入 UI，执行回归和真机验收；无数据库/文件迁移，无新增后端协议。
4. 回滚前停止阻抗并确认释放；移除新增入口与能力接线，既有 EEG 数据、导联库、算法和回溯不受影响。

## Validation

实施补充（2026-11-23）：`amplifier.h:59-85,169-170` 的阻抗请求选择 Reference 物理输入；输出按实际 SDK 表解码，允许独立 ImpedanceReference/ImpedanceGround，不能按同 index 覆盖普通输入。SDK User Manual rev8.1 §5.3/5.3.1 第14页规定最新状态、单样本、Ω。电极名称始终在圆圈内，读数始终在圈上；图保留480×480最小逻辑尺寸，小窗口滚动查看，颜色范围编辑放在右栏，减少对头图高度的占用。相同位置重叠仍以配置为准，不移动电极造出虚假布局。

记录目录在 Stop 前捕获，阻抗切换与普通停止复用保存后注册逻辑。原始写盘队列的粘性故障不改变：保存失败保持占用并保留已有记录，不能通过切换阻抗伪造成功；需先处理文件/磁盘问题并恢复记录。详细工程证据和待真机项目见 `docs/validation/acquisition-impedance-2026-11-23.md`。

- 纯契约：Ω→kΩ、渐变节点/插值/范围外饱和及非法输入、NaN/负值/无数据、乱序通道和 REF/GND 身份、无坐标、重复值通信语义。
- 生命周期假设备/原生边界替身：互斥打开、重复点击、取消、断连、关窗、写盘排空/失败、关闭失败、延迟旧回调、原生读未退出、配置与后台探测竞态。
- 集成回归：原始值/通道序/采样计数不变，算法传输没有阻抗批次；切回新会话不混入旧缓存；阻抗映射只使用采集配置中的物理通道身份。
- WPF：ViewModel 命令/绑定/选择同步/列表排序，BAML 构建；实际窗口与设备状态需单独人工验收，未运行不能声称已验证。
- 真机：设备序列与 SDK 版本、实际流通道表、REF/GND 支持、断开/重接电极的返回、真实刷新速度、多次 EEG↔阻抗、录制 finalize 后分段、USB 断连。保存带日期的最小验证证据，禁止提交个人 EEG 或连续测量转储。
- 执行聚焦桌面测试、必要的后端实时会话回归、文件规模校验、OpenSpec strict 与 git diff --check，分别记录模拟/硬件检查结果。
