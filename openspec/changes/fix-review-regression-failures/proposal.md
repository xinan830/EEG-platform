# Proposal

## Why
回溯回归存在 11 项失败：时间轴拖动未暂停真实播放时钟、分析呈现测试未经过当前算法选择流程、标注测试仍断言已被替换的界面，以及未配置的真实导出验收使用了当前运行器不支持的动态跳过。需要分别修复行为与验证入口，不能降低断言或把缺失验收报告为成功。

## What Changes
- 时间轴拖动期间暂停唯一播放时钟，释放时恢复拖动前状态，重复开始/结束保持幂等。
- 按当前已提交的双页签事件标注界面更新编译 WPF 行为和渲染测试，保留命令、权限、编辑与生命周期检查。
- 分析呈现测试通过真实算法选择及有身份的适配器进入，验证结果只发布一次且关闭时清理。
- 真实导出验收在未配置时于发现阶段明确跳过，部分配置错误仍失败，完整配置执行原有 HTTP 验收。

## Capabilities
### New Capabilities
无。
### Modified Capabilities
- `desktop/recording-review`: 明确拖动独占播放游标与恢复规则。

## Impact
影响桌面回溯导航、标注及分析测试与导出验收入口。不改变后端科学算法、原始文件、样本坐标、V/µV、通道顺序或 HTTP/WebSocket 契约；不引入依赖或迁移。回滚仅撤销本变更差异，保留工作区既有修改。
