# Design

## Context
见 proposal.md。当前规范已要求拖动暂停唯一播放时钟；实际导航只停止分析预取。标注界面在提交 99a3316 已改为 416 DIP / 48 DIP 标题栏及事件列表、标注编辑两个页签，旧测试仍引用已删除的控件。分析测试使用 AlgorithmId=unknown 的无类型协调器并绕过选择流程。

## Goals / Non-Goals
修复真实时钟状态并恢复有效回归覆盖。保留现有已提交的标注界面与科学处理线路，不为旧测试恢复已删除控件或添加 RBP 专用回退。

## Decisions
- 在导航状态所有者保存拖动前播放状态，调用现有 playback.Pause/Play 与 PublishPlaybackChanges；重复拖动通知幂等，关闭时不恢复已释放时钟。算法预取随时钟同向暂停、恢复。
- 分析测试复用有 rbp 身份的 PanelProvider，通过 OpenAnalysisAsync 进入当前生产路径，以已有历史集合与 Bands 通知验证发布次数。
- 标注测试使用真实双页签、历史行按钮及共享事件宫格，保留来源权限、编辑状态、非模态窗口和 DPI 渲染检查。当前界面已提交，恢复旧布局会撤销现有功能，故不采用。
- 使用项目现有 xUnit FactAttribute 的发现阶段 Skip；仅三项环境变量全部缺失才跳过，部分配置必须报错，避免把错误配置隐藏为成功。无需升级测试框架。

## Risks / Trade-offs
拖动暂停会触发既有波形恢复逻辑，需覆盖频谱与标量预取生命周期。完整真实 HTTP 导出依赖独立后端，未配置时不得宣称已验收。原始数据与已有工作区修改均保持原所有权，不新增存储。

## Migration Plan
无数据迁移；回滚本变更差异。验证原失败集合、全 Review、完整桌面测试、文件规模和 OpenSpec。
