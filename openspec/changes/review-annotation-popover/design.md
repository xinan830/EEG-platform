# Design

## Context

见 proposal.md。事件业务统一由 RecordingReviewViewModel 和 RecordingEventService 拥有；本次将事件加载/编辑与选点模式按职责提取到独立 partial，主 ViewModel 降至约 510 行，继续在规模登记中跟踪剩余编排职责。

## Goals / Non-Goals

将标注入口与非模态工具窗分离，复用父级 DataContext；不增加一套事件状态或持久化。按用户更正，窗口在常规操作时不得自动收起。

## Decisions

- 事件加载、创建、更新与编辑状态按职责从主 ViewModel 提取到 Events partial；交互模式由 EventPlacement partial 唯一持有。时间输入解析为录音绝对秒数并按采样率映射，精确保留旧区间样本时长。输入边界为 [0, sampleCount)，区间不得越过 sampleCount；持久化失败保留草稿，写入期间防重复提交。
- 波形交互放在独立 Canvas partial：仅绘图区使用实际 X 轴 VisibleRange 和 plot rect 做坐标换算，显示定义快照颜色的预览线；点选成功/拖动释放后提交，Esc 或取消清除预览不关闭工具窗。进入模式和直接拖动时暂停播放以固定坐标，不自动恢复。直接拖动需要超过系统拖动阈值，外部事件只能选择，不能拖动修改。
- 波形事件图形携带对应 RecordingEvent 以命中选择；生命周期线不参与。选点操作绑定固定的类型/事件目标，切换选择取消当前模式，关闭页面/工具窗/Dispose 清理交互。
- 拖动保留指针相对事件起点的偏移，避免抓取区间中部或标签时跳位；工具窗改位及同一事件的拖动同时保留编辑备注。重新播放取消选点，保持预览只对应当前暂停坐标。
- 复用工作台 WindowChrome 的自绘标题栏方式，以“事件标记”为唯一标题，系统命中测试提供拖动和缩放，自绘 × 关闭。窗口初始宽 344、高 570 DIP，按宿主可用高度收缩，正文可滚动；两种添加方式并排，空历史不展示无效操作。调用 Show 而非 ShowDialog，Owner 为回溯窗口，ShowInTaskbar=false、Topmost=false。首次按宿主客户区右侧位置和可用高度定位。
- 入口仅管理一个窗口实例及 IsOpen 呈现状态；再次点击 Activate 同一窗口，保留用户移动的位置。删除 Popup、失活关闭、外部点击关闭和 Escape 关闭逻辑。
- 新增与历史操作及编辑表单保留在同一窗口中，编辑状态继续使用唯一 ViewModel 属性；关闭后重开使用同一业务状态，不复制事件。
- 保持现有异步命令、采样时间换算、错误通知与来源保护。空列表给出说明并禁止无效操作。
- 生命周期边界：正常页面操作、失焦、按 Esc 均不关闭；用户手动关闭或回溯页面销毁/记录上下文更换时释放窗口，Closed 同步入口状态并结束编辑显示。
- 不引入第三方浮层库或跨会话位置设置。
- 根据用户选择优先易读性：将工具窗扩大至 384 DIP 宽并提高基础字号、输入框高度和分区留白；继续使用共享文本框样式与蓝白配色。窗口仍可缩小，正文滚动适配小宿主高度。
- 界面首先呈现“已标记事件”及其定位/编辑/删除操作，其后按需呈现编辑区，最后以分隔线和“添加新事件”组织新增流程。省略当前回溯位置卡片，避免它与标注管理抢占首屏注意力。
- “编辑”按钮使用同一个开关状态控制展开/收起及浅蓝选中样式；收起时同时取消未提交的波形改位，避免隐藏编辑区仍留在选点模式。

## Risks / Trade-offs

- 工具窗可遮挡局部波形 → 默认靠右，允许拖动与缩放，不阻断波形操作。
- 用户切换应用时窗口可能被其他应用遮挡 → 使用普通 owned window，不全局置顶；回到工作台或点击标注可重新激活。
- 标记交互不运行科学运算；保持样本时间、单位、通道顺序、质量与 provenance 不变，无后端测试适用。新点事件写入原事件 JSON，旧区间不迁移。

## Migration Plan

直接替换入口，不迁移磁盘数据。回滚新控件接入即可恢复布局；保留用户已有未提交修改。主视图规模登记随职责移除更新。

## Testing Strategy

使用已有 WPF STA fixture 实例化编译工具窗，验证默认右侧、WindowChrome 拖动区域/缩放边框/关闭命中测试、非模态交互、外部点击/Escape/失活保持、重开复用和位置保留、手动关闭与会话清理，并回归原命令绑定与权限。渲染空状态与有事件状态的 100%/150% 像素密度预览，检查命名与空状态可见性。运行事件相关测试、桌面构建、文件规模与 OpenSpec 校验。
