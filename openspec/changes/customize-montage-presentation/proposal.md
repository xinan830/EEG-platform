# 导联展示设置与公共颜色选择器

## 原因

导联表中的负极输入编号重复占用空间。已有显示顺序字段但编辑器只读，
且校验将非稀疏输出顺序绑定到源通道顺序。采集、回溯分别按行号使用固定
调色板。事件编辑器已有颜色选择交互，不能为导联再复制一份。

## 范围

- 抽出 Shared/Controls/ColorPicker，事件和导联统一使用。
- 删除负极输入编号展示列；保留正极编号和负极/参考选择及计算。
- 导联保存可选 RGB 颜色，支持上下移调整输出顺序。
- 采集和回溯读取导联快照颜色、顺序；保留旧配置读取能力。

## 不改动

原始样本、NativeChannelIndex、电极映射、参考公式、严格通道配置 ID 筛选、
滤波和算法计算均不改变。系统预设仍只读，复制后可以编辑。

## 验证

公共控件绑定/取消/禁用测试；配置保存重载、旧 JSON、排序、快照和投影测试；
后端采集导联信号契约测试；完整桌面测试和 Release 构建；OpenSpec、规模、
空白检查。真实设备颜色和 GPU 展示由人工验收，不以单测冒充硬件验收。
