# 设计

`MontageProfileCatalogue.Deduplicate` 是系统预设、持久化导联、回溯目录和算法注册
共用的目录边界。桌面刷新时先构造系统预设，再读取持久化配置，先按
`MontageProfile.Id` 保留首次出现的条目，再对名称以 `ANT默认通道配置 ` 开头的条目
建立语义身份，兼容旧版本错误写入的用户来源标记。语义身份包括预设名称、设备来源、
通道配置快照 ID、导联方向及参考集合，因此可以清除旧版本用不同 ID 持久化的同一系统
预设。同名但导联规则不同的用户配置不匹配该语义身份，仍按自己的 ID 保留。

TNK 算法页读取的是后端记录目录，不是采集准备页集合。后端目录按显示投影（标签、
版本、输出公式和源映射）过滤同一投影的不同快照 ID，因而旧 SQLite 快照不会再次把
同一导联显示多次。此过滤只改变返回目录，不删除历史快照或原始记录。

去重只作用于当前内存目录，不改写原始 JSON，也不改变历史记录中的 montage
快照。重复数据的持久化清理留给独立迁移，不在本缺陷修复中静默删除用户数据。
